# Calibration

"Not a finding" notes that `learn` mode accumulates from reviewer feedback. Each note records a kind of finding that reviewers repeatedly ticked as wrong or not worth raising, with the reason. Before briefing a lens, the orchestrator passes along that lens's notes and the notes under "all lenses".

Keep each note to one line and include the evidence count, e.g. `- (3 PRs) Do not flag numeric spacing classes inside the results list cards: the card density scale has no named tokens yet.`
