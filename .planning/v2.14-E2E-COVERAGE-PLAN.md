**Grounded flow map (verified this session).** The real OIDC redirect/exchange is **server-side**, which is decisive for the mock seam:
- **Entry:** `apps/frontend/src/routes/candidate/preregister/+page.svelte` (`data-testid="preregister-start"`, button text `…identifyYourselfButton`) calls `redirectToIdentityProvider()`.
