Replace the a11y scan harness's role-based settle with a **typed route contract** that makes
"the scan saw the route's real content" structural rather than per-site discipline (D-04), and
close the one genuine WCAG 2.1 AA failure that hardening exposes on the constituency selector
(D-17 Option A, operator-decided).

This is the phase's tracer: one thin path — test type → test runner → route walk → product
component → global CSS — wired end-to-end and proven by a real axe run in both themes. Every
later plan expands horizontally from this proven slice.

the suite ever noticing, because the scan settled on a static heading and ran against a DOM with
no data-driven content in it. The typed contract is the regression gate that would actually have
caught it — the real FIX-01 deliverable (D-01a).

Output: a `contentTestId`-required route table covering all six existing scans, an honest
constituencies scan, and an AA-clean constituency selector.
</objective>
