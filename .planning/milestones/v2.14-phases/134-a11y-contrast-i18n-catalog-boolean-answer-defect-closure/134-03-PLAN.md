## Reference: MF2 singular forms for `questions.multiChoice.selectExact` (D-18)

The `one` variant per locale. **These are constructed from the existing plural strings, not
natively authored** — the type-gen source carries only the plural form, so no singular exists
anywhere in the repo to copy. Confidence: HIGH for `en`, MEDIUM for the other six. Plan 07 files
the required UAT review item so a native speaker corrects them before milestone close (D-18).

| Locale | `countPlural=other` (verbatim from `translations/`) | `countPlural=one` (constructed) |
|--------|-----------------------------------------------------|----------------------------------|
| en | `Select {count} options.` | `Select 1 option.` |
| fi | `Valitse {count} vaihtoehtoa.` | `Valitse 1 vaihtoehto.` |
| sv | `Välj {count} alternativ.` | `Välj 1 alternativ.` |
| da | `Vælg {count} muligheder.` | `Vælg 1 mulighed.` |
| et | `Vali {count} valikut.` | `Vali 1 valik.` |
| fr | `Sélectionnez {count} options.` | `Sélectionnez 1 option.` |
| lb | `Wielt {count} Optiounen.` | `Wielt 1 Optioun.` |

Take the `other` column from the type-gen source file itself rather than from this table — the
table is here to supply the singulars and to make the pairing legible, not to replace the source.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| catalog JSON → compiled client bundle | Message values are static build-time content compiled by Paraglide into the client bundle; they are authored in-repo, never user-supplied. |
| message interpolation params → rendered text | `{count}`, `{min}`, `{max}` come from `multiConstraints` (numbers derived from question configuration), not from request input. |
