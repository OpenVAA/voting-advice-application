<objective>
Convert `trackingService` — the ONLY spread-consumed app-layer producer (`...tracking` at `appContext.svelte.ts:299`) — from a factory closure into a Svelte 5 class, while preserving the spread-safety of its reactive members. CLASS-03.

This is the single most spread-sensitive conversion in the phase. Svelte 5 compiles bare `$state`/`$derived` CLASS fields to private backing fields + PROTOTYPE accessors, which are NOT own-enumerable and are DROPPED by `{ ...instance }` spread (the Phase 107 spread-safety gate, recorded in STATE.md). The current producer already sidesteps this: its `shouldTrack` / `sessionId` / `sendTrackingEvent` are exposed as OBJECT-LITERAL `{ get current() {...} }` handle objects, which are own-enumerable VALUES and therefore spread-safe by construction. The simplest byte-identical conversion KEEPS those handle objects as instance fields holding the handle objects — the spread copies the field values (the handle objects) intact.

Purpose: appContext (Phase 109) must compose a class-based trackingService whose reactive surface still survives the existing spread until the Phase 109 spread-of-context fix lands.
Output: `class TrackingServiceImpl` + `trackingService()` factory wrapper, signature byte-identical, RuneTrackingService return type unchanged.
</objective>
