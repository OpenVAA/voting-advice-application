    is still re-included verbatim because flat config replaces rather than merges.

    The new `component-stores.svelte.ts` (created in Plan 01) matches `src/**/*.{ts,svelte}`
    because the `.ts` segment of `.svelte.ts` matches the `{ts,svelte}` brace group, so it
    is now covered by the guard and (post-SWEEP-01) is clean.
