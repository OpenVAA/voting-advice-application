<objective>
Eliminate the `dataRoot` alias-indirection reactivity staleness on cold/direct-URL
entry to data-dependent routes, document the hole in CLAUDE.md, and add cold-entry
E2E coverage that locks the regression (proven via a negative control).

This is the substance of Phase 117 — it produces the source fix (COLD-01), the doc
carve-out (COLD-02), and the new cold-entry regression coverage + negative control
(COLD-03 authoring). Plan 02 runs the full-suite green gate that closes the phase
(Phase 116 GATE-01).

Purpose: A real user-facing bug — cold/direct-URL entry to `/elections`, `/info`
(and the candidate/admin election regions) renders an EMPTY list because an
intermediate `const dataRoot = $derived(ctx.dataRoot)` alias yields a
referentially-identical `DataRoot` on every `#version` bump, so Svelte 5 skips
downstream notification (root cause LOCKED — debug `dataroot-stale-direct-nav` +
Spike 024, 4/4). Per COLD-01/02/03 and the locked CONTEXT decisions.

Output:
- 12 consumer sites rewritten to direct `ctx.dataRoot.<prop>` reads (1 already fixed
  by the operator → confirm/commit; 11 to rewrite). 2 imperative writers left.
- CLAUDE.md "Context Destructuring Rule" carve-out.
- New cold-entry E2E spec + a `cold-entry-dataroot` Playwright project + a
  data-dependent testid on the info election region.
- Negative-control evidence the spec RED-fails on the pre-fix shape.
</objective>
