## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Same display names across templates | perm-disjoint-1co and perm-not-located-2e2cg both used `[EL1] Region election` / `[EL2] Municipal election`. Cross-contamination during full-suite races misleadingly looked like disjoint-1co leaking when it was actually not-located-2e2cg | advisory | When adding a new perm-* template, give it display names that are unique within the family. Existing duplicates kept because the contamination is now structurally prevented by `data-setup-baseV1`'s `extraTeardownPrefix: 'e2e-perm-'`. |
| `data-setup-baseV1` racing with last perm teardown | `data-setup-baseV1.dependencies = ['perm-not-located-2e2cg']` and `data-teardown-perm-not-located-2e2cg` (wired via the setup's `teardown:` key) both fire after the last perm spec finishes — they race. If baseV1 setup finishes first, perm rows linger into mega-journey runtime | advisory | `baseV1.setup.ts` passes `extraTeardownPrefix: 'e2e-perm-'` so it defensively wipes perm rows before seeding. Any new "tail" chain wired the same way must apply the same defensive teardown. |
| Playwright forbids setup→teardown dependencies | A natural-feeling fix was `data-setup-perm-2e-shared.dependencies = ['data-teardown-perm-1e1cg1co']` (wait for prior teardown), but Playwright errors at config-load time with "must not depend on a teardown project" | advisory | Sequence chains via the previous SPEC project; use `extraTeardownPrefix` on each subsequent setup to defensively wipe the family prefix. |
| AccordionSelect collapses after selection | The voter results-page election picker auto-collapses (DELAY.lg) after the first selection; subsequent clicks find only the active option in the DOM. Looking for any other option times out | advisory | `expectElectionOptionAndSelect` re-expands the accordion by clicking the visible (active) option when only one option is in the DOM. ## Critical Anti-Patterns (do NOT repeat these)

- ANTI-PATTERN: clearing `test-` from inside a perm-* setup while baseV1 was active → would wipe baseV1's seed mid-run. Mitigation: structural — perm-* family is now sequenced BEFORE baseV1, so perm-*'s `extraTeardownPrefix: ['test-', 'e2e-perm-']` runs when no baseV1 data is present.
- ANTI-PATTERN: setup→teardown dependency in playwright config → forbidden by Playwright at config-load. Mitigation: always wire next setup to previous SPEC; use `extraTeardownPrefix` for defensive cleanup.
- ANTI-PATTERN: `getByRole('button')` on accordion-select options → AccordionSelect exposes ARIA `option` roles. Mitigation: documented in voter-mega-journey.spec.ts helper comment.
