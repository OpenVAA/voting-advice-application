Steps passed cleanly (per trace inspection):

    (88-01 surface — no 88-04 changes)

  - T5: result-card-contents (fixture-driven, 4 score-gauges, election-symbol "10",
    test-qu-info-text answer) — PASS
  - T6: matching: organisations (5 outer / Party BB 2 / Party AA 3-show-all-5-
    collapse) — PASS
  - matching: ranking (88-01 surface) — PASS
  - T7: candidate details matrix on CA-AA-Special (4 voter-vs-entity matrix
    points via entityDetails.expectQuestionDisplay) — PASS
  - T7: organisation details ([info, children, opinions] tabs + 3 regex
    info-items + 5 member-cards via entityDetails fixture) — PASS
  - T8: filters: text (polar → 2 cards Polar-Max+Polar-Min, clear) — PASS
  - T8: filters: dialog stage 1-3 (3 filter rows, No-answer option visible
    with count badge, setSelection → 1 card 'Free Independent', badge=1) — PASS
  - T8: filters: dialog stage 4 (close (d1) succeeds, reopen (d2), reset)
    — PASS through reset; FAILS at d2.close()

Cause analysis: the d2.close() invocation calls
  dialogRoot.getByTestId('entity-filter-dialog-apply').click()
where dialogRoot is the re-opened modal. The internal Modal element
keeps the <dialog> in the DOM across open/close cycles (using `hidden`
class), but on the SECOND open the testid 'entity-filter-dialog-apply'
is not reliably resolved inside the dialogRoot scope. The fix would
require either:
  - Using getByRole('button', { name: /Close filters|apply/i }) instead
    of testid lookup inside the modal scope, OR
  - Stripping the dialog element from DOM on close (rather than
    hidden-toggle), OR
  - Re-resolving the dialogRoot freshly per close call rather than
    binding it to the openFilterDialog return value.

This is identified as a deferred follow-up (filed in
deferred-items.md alongside the matrix-step heading-regex pre-existing
bug). The contracts that T8 wanted to enforce ARE coded into the spec
and pass for the first 3 stages — the failure is at the fixture-level
modal re-open dynamics, not at the data assertions.

3-run gate is explicitly deferred to 88-LAST per SCOPE acceptance #8.
This single cold-start green run is a PARTIAL accomplishment: 5 of 6
new T5-T8 cells pass; the 6th (T8 filters:dialog) passes 4 of 7 stages
before tripping on the fixture re-open dynamics.
