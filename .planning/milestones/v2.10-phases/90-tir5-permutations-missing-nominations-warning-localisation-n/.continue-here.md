## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Cross-plan wiring gap from "deferred-to-next-plan" handoffs | Plan 90-01's SUMMARY claimed the +layout.ts wiring was "deferred to Plan 90-03"; 90-03's task list never absorbed it. Result: a runtime-override surface with no production caller. Verifier caught it as Gap #1. Contributed to the eventual full revert. | advisory | When a SUMMARY defers work to a downstream plan, the downstream plan's `must_haves` MUST contain a truth referencing the upstream SUMMARY decision by number. Plan-checker should flag the absence. |
| Building on a framework surface without checking its compile-time invariants | Stage A treated `DynamicSettings.i18n.supportedLocales` as a runtime degree of freedom, but Paraglide bakes `baseLocale` at compile time + maps URL patterns from it. Result: silent UI vs state divergence when override defaults differ from baseLocale. Discovered after shipping + verifying; led to revert. | advisory | Before designing a runtime override against a framework's settings surface, audit the framework's compile-time vs runtime split. Document the divergence boundary (or its absence) in the discuss-phase output before planning. |
