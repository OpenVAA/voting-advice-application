<!-- SHA-identity comparator script signature (per RESEARCH §"3-Run SHA-Identity Gate Mechanism"): -->

The forked sha-identity.mjs script:
- `loadRun(path)` — parses Playwright JSON reporter output (strips header line if present via `_braceIdx = _raw.indexOf('\\n{')`)
- `categorizeStatus(raw, err)` — maps {'passed' → 'pass', 'skipped' → 'cascade' if err matches /did not run|setup.*failed|dependency.*failed/i, else 'cascade' generically for skipped, else 'fail'}
- `flattenReport(rep)` — walks suite tree → array of "<projectName> :: <specFile> > <specTitle>|<status>" lines
- `hashRun(path)` — sort flattened lines, join with '\\n', sha256

Verdict logic:
- STRICT-PASS: all 3 SHAs identical
- ALMOST-STRICT-PASS: run-2 == run-3 (run-1 operator-acknowledged invalid baseline) — Phase 86 precedent
- FAIL: runs 2 + 3 diverge → diff emitted; non-zero exit
