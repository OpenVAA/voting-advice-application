### 86.2-03: All-green-suite gate + close (4 commits)
- Operator override: dropped SHA-identity gate (D-06) in favor of absolute 157/0/0/8 verdict baseline
- **Run 1 (pre-fix):** 87 PASS / 1 FAIL / 77 SKIPPED — CAND-03 image upload failed
- **Run 2 (pre-fix):** 86 PASS / 1 FAIL / 78 SKIPPED — registration ToU `toBeHidden` failed (flake rotated upstream)
- Tested the documented JWT-rotation `refreshSession()` fix in `_setPassword`/`_resetPassword`/`_register` (commit `ad922cbc3`)
- **Run 3 (with refresh fix):** 86 PASS / 1 FAIL / 78 SKIPPED — same registration failure → hypothesis disproved
- Reverted `refreshSession` fix (commit `a00c521bf`) — adds network round-trip per password op with no observed benefit
- **Root cause found:** Operator inspection of `candidate-profile.spec.ts` revealed `test.beforeEach` was unregistering the candidate between tests in a serial-mode describe block. Test 1 registered successfully; `beforeEach` then ran again before test 2, wiping the registration; test 2's `loginAsCandidate` failed because the candidate no longer existed.
- **Fix (commit `3f638b03c`):** `test.beforeEach` → `test.beforeAll`. Under `--repeat-each=N`, Playwright re-executes the describe block N times so `beforeAll` still re-runs each iteration, preserving the original `--repeat-each` fresh-invite-flow goal.
- **Three manually verified post-fix cold-starts:** all produce **157 PASS / 0 FAIL / 0 CASCADE / 8 SKIPPED** — the locked baseline
