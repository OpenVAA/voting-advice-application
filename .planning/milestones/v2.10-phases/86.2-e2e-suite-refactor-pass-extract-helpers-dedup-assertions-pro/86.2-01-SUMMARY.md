**2. [Rule 1 — Naming convention] `T` → `TTable` generic name**

- **Found during:** Task 2 lint step.
- **Issue:** Plan specified `<T extends string>` for `assertDbRowCount`. Project `@typescript-eslint/naming-convention` rule requires generics match `/^T[A-Z]/`; bare `T` fails the rule.
- **Fix:** Renamed generic to `TTable`. No call-site impact (generic is inferred from `table` argument).
- **Files modified:** `tests/tests/helpers/db-precondition.helper.ts`.
- **Commit:** `4e5b0f043`.

**3. [Rule 1 — TS strict] `probe.data` undefined-narrowing in assertDbRowCount**

- **Found during:** Task 2 tsc step.
- **Issue:** `FindDataResult.data` is typed `Array<...> | undefined` (NOT a discriminated union on `type`), so `probe.type === 'success'` does NOT narrow `data` to defined. Original anchor pattern used `electionRows = electionsProbe.data ?? []`; helper-extracted version dropped the `?? []` defense and tripped `TS18048: 'rows' is possibly 'undefined'` (also when eslint autofix changed `rows.length` to `rows` argument).
- **Fix:** Explicit `(probe.type === 'success' ? (probe.data ?? []) : []) as Array<Record<string, unknown>>` — restores anchor semantics + satisfies strict mode.
- **Files modified:** `tests/tests/helpers/db-precondition.helper.ts`.
- **Commit:** `4e5b0f043`.

**4. [Rule 3 — Blocking, scope expansion] Pre-existing parse error at voter-not-located-redirect.spec.ts:195**

- **Found during:** Task 3c lint + tsc + smoke.
- **Issue:** `expect( , 'electionUuid must be discovered in beforeAll').toBeTruthy();` — empty first argument is a SyntaxError that prevents the entire spec file from loading. Pre-existing from commit `97f55cb41 chore(87-post-fix)` (the D-02 "treated as final" commit per Phase 86.2 CONTEXT.md).
- **Fix:** Replaced with intended `expect(electionUuid, 'electionUuid must be discovered in beforeAll').toBeTruthy();`. Inferred intent from immediately-following line `const deferredTarget = \`/results?electionId=${electionUuid}\`;` which would fail at runtime on a falsy electionUuid.
- **Why this is Rule 3, not Rule 4:** The pre-existing error BLOCKS the spec file from loading entirely (Playwright "No tests found" error). Without the fix, Task 3c's smoke could not validate that my refactor is correct (no tests would even attempt to run). The fix is mechanical (1-arg restoration) with clear intent, NOT an architectural change.
- **Files modified:** `tests/tests/specs/voter/voter-not-located-redirect.spec.ts`.
