Helpers available via `import { ... } from '../../helpers';`:
- `settleNetworkIdle(page, opts?)` — opts: `{ waitUntil?: 'load' | 'domcontentloaded' | 'networkidle'; timeoutMs?: number }`. Default `waitUntil: 'networkidle'`, `timeoutMs: 10_000`. Does NOT swallow timeouts; caller adds `.catch(() => null)` post-call where needed (Pitfall #1).

- `expectLandedOn(page, pattern, opts?)` — pattern: `RegExp | string`; opts: `{ timeoutMs?: number }`. Default `timeoutMs: 10_000`. Positive-only (negative `not.toHaveURL` stays inline).
- `clickAndRaceSettle(locator, destinationPredicate, opts?)` — Internal swallow (do NOT propagate to advanceClick or missingNominations.ts).
- `iterateSelectOptions(page, comboboxLocator, opts?)` — Narrow (multi-combobox + `.first()` option). NO propagation beyond anchor (named-combobox variants are v2.11+).
- `assertDbRowCount(client, table, filter, expectedCount, opts?)` — NO propagation beyond anchor.
- `walkVoterIteration(page, opts?)` — NO propagation beyond anchor (results-sections answer-loop is a different pattern).
