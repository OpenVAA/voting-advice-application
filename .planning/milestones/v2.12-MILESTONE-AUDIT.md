## Carried forward to v2.13

The context-as-class migration (v2.13) absorbs everything still wanted from v2.12:

- **HANDLE-02/03 (re-shaped):** consumers still need the `.current` reads flattened — but to **bare class
  fields**, not the get/set-accessor idiom. The class conversion does this, and additionally **drops the
  `reactiveFoo`/`Foo` duplicate handles** (e.g. `reactiveDataRoot` + `dataRoot` collapse to one reactive
  `dataRoot`) and **removes the Phase-102 `_poc*` scaffolding** (`_pocDarkMode`/`_pocAppType`/`_pocGetRoute`
  + the `_poc*` PoC test objects).
- **RENAME-01/02:** Store→State rename — carried verbatim.
- **SWEEP-01/02/03 + GATE-01:** straggler clearance (last `svelte/store`, `$:` debug line, app-wide ESLint
  guard) + milestone-close green gate — carried verbatim.

## Landed in the working tree (outside the GSD phase structure)
