Grep gates below prove each marker survives.

- **`onMount` `?start=` handler (Pitfall 3):** The leaf's `onMount` (`?start=` → set `firstQuestionId`, fire `question_startFrom`) currently fires once per leaf mount; since the leaf already reuses across hops today, `onMount` already fires once per session (start is only present on the entry URL).
