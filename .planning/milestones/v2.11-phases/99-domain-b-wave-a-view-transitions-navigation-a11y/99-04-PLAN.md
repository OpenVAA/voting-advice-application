## Artifacts this phase produces (new symbols)

- `LayoutContext.routeTitle` — a reactive `RouteTitle` signal exposing `readonly current: string` (the active route's localized title; empty string when no title-bearing component is mounted). Declared in layoutContext.type.ts, implemented in layoutContext.svelte.ts.
- `LayoutContext.setRouteTitle(title: string)` — a declarative, `$effect`-scoped registrar (analogous to `useTopBar`/`usePageStyles`): the mounted title component calls it with its localized `title`; it writes the signal and, on component teardown via `$effect` cleanup, resets the signal to empty string so a route without a title-bearing component does not announce a stale title.

No new i18n keys. No new files (the signal lives on the existing layoutContext).
