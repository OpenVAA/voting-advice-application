<the_contract>
The names below are fixed by this plan; plans 176-06 to 176-17 and Phases 177 and 179 read them.

**`unanswered.ts`**

- `requiredInfoQuestionsOf(infoQuestions)` — the info questions that are required and not locked.
- `unansweredQuestionsOf(questions, answers)` — the questions with no saved answer. With no answers object every question is unanswered: that is the one statement of "no entity loaded".

**`taskState.ts`** — imports nothing; route names and message keys are structural literal unions.

- `TaskId` — `'nomination' | 'profile' | 'questions'`. `TaskStatus` — `'complete' | 'incomplete' | 'blocked'`.
- `TaskRoute` — a route descriptor a page hands to its route builder: `{ route: 'ContestantAppNominations' }`, `{ route: 'ContestantAppProfile' }`, `{ route: 'ContestantAppQuestions' }`, `{ route: 'ContestantAppQuestion'; questionId: string }`, `{ route: 'ContestantAppEntityHome' }`, `{ route: 'ContestantAppPreview' }`.
- `Task` — `{ id: TaskId; status: TaskStatus | undefined; route: TaskRoute; resume?: TaskRoute; count?: number }`. `status` is `undefined` while the facts it rests on are not loaded. `resume` is on the questions task alone, while a question is unanswered: the first unanswered question.
- `NextStep` — `{ task: TaskId; route: TaskRoute }`.
- `TaskState` — `{ tasks: ReadonlyArray<Task>; nextStep: NextStep | undefined; previewOpen: boolean; known: boolean; allComplete: boolean }`.
- `TaskStateInput` — `{ entityKnown: boolean; hasNomination: boolean; questionsReady: boolean; unansweredRequiredInfoCount: number; requiredNameMissing: boolean; opinionCount: number; unansweredOpinionCount: number; firstUnansweredOpinionId: string | undefined }`, one doc line per member.
- `hasNomination(nominations)` — true for a list with at least one element; false for an empty list and for no list.
- `previewOpenOf({ hasNomination, unansweredRequiredInfoCount, unansweredOpinionCount })`.
- `taskStateOf(input)`.
- `taskLabelKey(task, answersLocked)` — the key of a task row's label, which is also the home's main action's.
- `ContinueTarget` — `{ route: TaskRoute; continues: boolean }`: where a button leads and whether its label is a "continue" or a "return".
- `homeAction(state)` — `{ kind: 'pending' }`, `{ kind: 'task'; task: TaskId; route: TaskRoute }` or `{ kind: 'preview'; route: TaskRoute }`.
- `profileSaveTarget(state)`, `questionSaveTarget(state, { wasUnanswered })`, `nominationsViewTarget(state)` — each a `ContinueTarget`; the last is `undefined` while the entity has a nomination and the state is not known.
- `questionsResumeRoute(state)` — the questions task's `resume`, or `undefined`.
