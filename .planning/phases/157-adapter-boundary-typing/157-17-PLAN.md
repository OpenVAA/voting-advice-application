Rename and rework `logDebugError` into structured, pino/OTL-conformant output across every call site,
in one codemod (D-F5, REVIEW-ADP-06's second half; the reviewer's comment at `getUserData.ts:31`).

logging idioms — which is the exact shape this phase exists to remove elsewhere. The forcing function

survival.

a rename for about 80 sites and a hand edit for 5.

This plan runs LAST among the implementation waves because it touches files every other wave also
touches.

anywhere.
