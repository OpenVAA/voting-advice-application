<objective>
Install the source test that fails when adapter specifics appear outside their allowed loci
(REVIEW-ADP-06, criterion 6's first half; D-F4).

The phase's one genuinely open technical question was answered by measurement rather than reasoning:
**`no-restricted-imports` does NOT catch the measured leakage.** All eight leaking route files reach
`event.locals.supabase`, a MemberExpression, and that rule inspects `ImportDeclaration` nodes only.
Five of the eight have no Supabase import at all. So the guard is a PAIR of rules, exactly as the
existing `svelte/store` guard already is, and that guard's own comments say so in-file.

Decision A is recorded and executed here: **an explicit eight-entry allowlist, annotated per entry with
its Phase-158 disposition.** `157-16` then takes one entry off it, so the list ships shrinking rather
than as a permanent amnesty.

Output: paired rules, an annotated allowlist, a guard self-test that proves the rules fire, and the
NEW halves of the negative control.
</objective>
