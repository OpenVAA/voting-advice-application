<objective>
Extract the standalone multi-text component's input part into the main input component and apply the
same extraction to the other complex branches, landing multilingual support for multi-text rows in the
same change, per D-H2 option (a) — the extract-and-import variant, not the wholesale fold.

Purpose: this is the phase's only item that ADDS behaviour rather than moving it, which is why it runs
last. D-H2 chose extraction over folding to keep the main input component from growing past nine hundred
lines while making the reviewer's own acceptance wording structural: each text item behaves much the
same as a normal multilingual text item. The option that kept multilingual and deferred the
consolidation was explicitly rejected, so both halves land together.

Output: four extracted part components with co-located prop contracts, a widened input type union, a
slimmer main component, a consumer with its type-level apology deleted, and a component unit test.
</objective>
