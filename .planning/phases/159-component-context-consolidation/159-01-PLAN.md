consolidation work starts, and commit the two source-scan guards that later waves depend on.

Purpose: criterion 1 is the phase's only item that can reintroduce the Phase-61 / Spike-024 bug class,

here is authored against Phase 152's convention (a literal dash, never an escape sequence).

new component unit test, two committed source-scan guard tests, and an extended cold-entry E2E negative
control.

confirmation checkpoint, deliberately. A confirmation checkpoint is auto-approved in unattended mode,
which is exactly the mode in which an out-of-space condition would void the phase's cardinal gate
unobserved. A failing threshold halts through the standard unmet-precondition path, which does put a
human in front of it.
