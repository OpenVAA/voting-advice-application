Replace `EntityCardAction` with a snippet inside `EntityCard.svelte` and delete both the component and
its type module, per D-H3 option (a).

action", which Svelte 5 expresses natively. The conversion is mechanical but carries one blocker the
decision does not mention and three invariants the end-to-end suite depends on, so the order of
operations matters: the scoped style rule must move first, because a snippet has no style scope and the
rule's absence has no compiler or static-render signal.

the results layout that refers to the component by name.
