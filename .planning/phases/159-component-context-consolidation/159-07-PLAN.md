<objective>
Extract the duplicated question-category rollup out of the two orchestrating context classes into one
shared utility, and move the array-content equality helper to the bottom of its own file, per criterion
5 and D-H5's sibling reasoning.

Purpose: the same rollup is written twice with three deliberate differences, and neither copy documents
that fact. The extraction is the phase's single highest-risk reactivity operation: the block being
extracted opens by reading the identity-stable data root, and the whole Spike-024 staleness class turns
on whether that read stays inside a tracking scope. The current code is already correct; the extraction
is safe only if it preserves that property exactly.

Output: one shared rollup utility with a unit test, two context classes calling it from inside their
existing effect bodies, and the equality helper relocated with its explanatory comment intact.
</objective>
