  <action>
    Write a dependency-free Node ES module under the phase directory that walks `apps/frontend/src`,
    finds every `$effect(` occurrence, extracts each body by balanced-brace matching, and classifies it
    against the predicate RESEARCH § Census Mechanics states verbatim. Adopt that predicate as written
    and quote it in the script header so the census's uniformity is inspectable rather than asserted.

    Three properties the script must have, each of which is a probe edge this plan owns.
    First, occurrences are keyed by path, line AND column, so two openings on one line and an effect
    nested inside another effect's body are distinct rows; sort by that triple, which makes the output
    deterministic and re-runnable.
    Second, buckets are mutually exclusive by a precedence order declared as an ordered list at the top
    of the file, so a body that both writes a bindable prop and is conditional lands in exactly one
    bucket; the sum of bucket counts must equal the row count and the script must assert that itself.
    Third, a body with no assignment is a first-class classification, not a parse failure — the script
    throws only when it cannot find its scan root or cannot balance a body, never when a body is empty.

    Add the four operational buckets the mechanical predicate cannot compute, sourced from 159-02's
    recorded evidence: a bucket for a target that has a second writer elsewhere in the module, and a
    bucket for a target written by a child through a two-way binding. The script marks candidates for
    these buckets by a stated heuristic and flags them for the hand-review column rather than silently
    deciding them.

    Provide a total-assertion flag. Demonstrate all three assertion behaviours from the `behavior`
    block and record the three outputs in the plan summary. Author every comment with a literal dash
    character, never an escape sequence (D-N1).
  </action>
