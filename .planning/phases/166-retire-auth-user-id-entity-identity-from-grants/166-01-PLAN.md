<assumption_delta_decision>
- noun: the entity-scope grant row `(user_id, entity, <type>, <id>, editor)` in `public.grants` is the
  primary identity link between an auth user and an entity.
- decision: promote. The grant becomes the only link; the per-row auth link column on `candidates` and
  `organizations` is removed in 166-03 rather than kept alongside. Keeping both would leave two links
  that can disagree, and an organization could never record a second editor in a single column.
- consequence accepted: one editor per candidate (D-11's partial unique index) keeps the candidate
  identity singular, while organizations become multi-editor (SC4).
- invariant test: `36-entity-identity.test.sql` pins both constraint names (an exact duplicate grant ->
  `grants_user_scope_target_role_key`; a second user on one candidate -> `idx_grants_one_candidate_editor`)
  and the ambiguity error. A future change that reintroduces a second identity source, or reorders the
  two unique checks, reddens that file.
