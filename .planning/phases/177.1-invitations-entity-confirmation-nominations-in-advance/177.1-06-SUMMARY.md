- **The journey header was updated with the step bodies.** Its step 3 and step 12 lines described what the step seeds and reads, so they were made true together with the bodies.
- **A second README sentence was corrected.** Line 422, "Seeding an invitation for one confirms it", was false. The README is in this plan's list, so it was corrected to "An invitation confirms one only when its call says so".
