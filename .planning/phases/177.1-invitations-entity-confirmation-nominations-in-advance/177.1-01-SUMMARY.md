### Auto-fixed Issues

**1. [Rule 1 - Bug] The functions-mount check misread this worktree's own stack**
- **Found during:** Task 1, the first run of the shared-stack refusals against the live stack.
- **Issue:** Docker Desktop reports the edge runtime's bind-mount source with a `/host_mnt/` prefix. The comparison with this worktree's `apps/supabase/supabase/functions` therefore failed and refused this worktree's own stack.
- **Fix:** Both drivers strip the `/host_mnt/` prefix before comparing.
- **Files:** `177.1-gates.sh`, `177.1-e2e.sh`.
- **Verified:** on the real stack and on a scratch harness.
- **Commit:** `b39fb8a22`.

**2. [Rule 3 - Blocking] Worktrees absent from disk**
