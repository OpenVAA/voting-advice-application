1. **The drivers are copied and adapted, not rewritten.** From Phase 178: `178-gates.sh`, `178-e2e.sh`, `178-verdict.mjs`. `$P178/178-01-SUMMARY.md` § *Deviations from Plan* is read first; every deviation it lists is in the files copied and stays.

3. **O-2.** The gate driver's power record lists the host's Sleep entries and nothing more; no driver line calls a run VOID except where it reads the wrapper's marker.
4. **The shared stack.** Both drivers gain three refusals (rules § *The shared local stack*): an in-flight run in any worktree of the repository, a listener on 5173 or the wrapper's port, and a running stack whose edge runtime serves another worktree's functions.
5. **`177.1-arity.mjs` is new**: the J1 and D-20 sweeps change the number of arguments of every call of `create_invitations` in SQL, and a line count cannot tell a call from a comment. It counts calls of a named function in a file (or standard input), skipping `--` comments and single-quoted literals (with `''` escapes), and fails on any call whose top-level argument count differs from the one asked.
6. **No operator round is read.** The operator ruled J1–J4 and the research's two open questions on 2026-10-17, each recorded in `177.1-CONTEXT.md`; the facts file records the two headings that hold them, and nothing else is interpreted.
