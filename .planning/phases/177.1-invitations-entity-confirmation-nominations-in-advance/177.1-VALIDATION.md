## Sampling Rate

- **After every task commit:** the touched pgTAP files alone on a reset DB, or the dev-seed unit tests; `yarn typecheck` once the callers compile.
- **After every plan wave:** the gate set (a `--rows` subset where the plan touches no database); an E2E close for plans that change a dataset or a spec.
- **Before `/gsd-verify-work`:** full gate set + one full green E2E run + `contestant-journey` and `invitation-contract` three times each in isolation, none VOID.
- **Max feedback latency:** 120 seconds for the per-task checks.
