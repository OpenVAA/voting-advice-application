## Shared Patterns

- **plpgsql RPC conventions** (503/506): `SECURITY INVOKER`, `SET search_path = ''`, fully qualified names, `22023` with `<fn>: <arg>[%] …` messages, and an explicit `REVOKE … FROM PUBLIC, anon` plus `GRANT … TO authenticated, service_role` after every function.
- **Schema change workflow:** edit `schema/`, then in the same commit run `yarn schema:regenerate` and `yarn db:types`. `assert:schema-migration-parity` is byte-strict.
- **Errors in TS clients:** throw `Error` naming `error.code` only, never the message (PII rule in dev-seed `createInvitations`).
- **Comment hygiene** under `apps/`, `packages/` and `tests/`: describe current behaviour only, with no "previously" and no plan ids. This applies to the reworded journey, `base.ts` and `voter-journey` comments.
- **Shared stack:** no db-reset, gate or E2E run until the operator says the `-infra` worktree is idle.
