<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller-supplied bearer token to `send-email` | The decoded `user_roles` claim drives the `isAdmin` predicate authorising a bulk send. |
| caller-supplied template and variables to the renderer | Subject and body text and their substitution variables arrive in the request body. |
| Edge Function to the SMTP relay | Host, port and sender identity come from configuration; credentials are optional. |
| database variable resolver to the renderer | `502-email-helpers.sql` produces the flat keys the renderer looks up. |
