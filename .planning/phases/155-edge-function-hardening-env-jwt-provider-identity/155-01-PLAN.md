<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet to `/functions/v1/identity-callback` | The function is served `--no-verify-jwt`; anyone can POST an `id_token`. This is the phase's principal trust boundary. |
| external IdP (Signicat/Idura) to Edge Function | Token signature is checked against a remote JWKS; the claim bindings decide WHICH issuer and WHICH relying party that signature is accepted for. |
| Edge Function to Supabase auth admin API | The function holds the service-role key and creates users, assigns roles and generates magic links on the strength of the verified token. |
| operator configuration (Supabase secrets, `.env`) to Edge Function runtime | Absent configuration previously degraded verification silently; after this plan it fails loudly. |
