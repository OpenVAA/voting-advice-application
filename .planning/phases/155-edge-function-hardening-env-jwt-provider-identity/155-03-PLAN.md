|----------|-------------|
| public internet to `/functions/v1/identity-callback` | Served `--no-verify-jwt`; the request body carries both the token and an optional `project_id`. |
| external IdP to Edge Function | The provider type read from configuration selects which claim map is applied to a verified token. |

| provider documentation to our identity model | The uniqueness of the account key is a property owned by the provider, which is why it is verified by citation. |
