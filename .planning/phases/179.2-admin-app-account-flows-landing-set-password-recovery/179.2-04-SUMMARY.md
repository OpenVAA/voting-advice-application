### A defect found by the full run, and fixed

- **Symptom.** `179.2-final` failed one test. The test was `admin-access` › "a session ended elsewhere with no signal to this tab: a link from the login form into the app reaches the login form, and so does a reload". Its error was `Back settled neither on the home nor on the login form`, and 24 dependent tests did not run.
- **What the trace showed.** That run wrote one home history entry, so the test's second Back reached `about:blank`. In the red run `179.2-04-red-4b`, the same login wrote two home entries.
- **Cause.** The Admin App's login handler called `update()` and then `applyAction(result)`. For a redirect, each of these runs a `goto` to the home, so the number of home entries varied from run to run.
- **Fix (`7fe36c5e3`).** On success the handler now navigates once, as the Contestant App's sign-in does. The two Back tests of `admin-access` now go back once from the home and assert the login page's entry.
