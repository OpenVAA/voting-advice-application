<objective>
Sweep the heaviest single concentration of planning narrative in the repository: the Playwright configuration
file, plus the E2E suite's shared utilities and fixtures.

`152-RESEARCH.md` § 4.4 measured `tests/playwright.config.ts` at **52 reference spans / 74 reference lines**
pre-sweep — the largest single-file concentration in the tree and roughly **8% of the whole 642-span judgement
surface**. That is why it gets its own plan rather than being folded into the E2E specs.

**Scale note, so a later reader does not think this drifted.** CONTEXT.md fact 7 sizes the planning-reference
class at 817 comment lines (tests 223). `152-RESEARCH.md` § 4 re-measured it at HEAD `22c2542e3` as **888
citation lines / 942 union / 946 occurrences / 642 comment spans across 278 files**, with tests at **257**
lines rather than 223. The measured figures govern, per CONTEXT.md § 0.1's own rule that where a fact and the
roadmap disagree the fact wins.

**The judgement standard is D-A1's, not a delete-everything pass.** Option (d) — full class, delete by default
— was explicitly rejected because it *"destroys measured hazard notes that no other document holds."* The rule
for every span: strip the citation; if what remains states something live about the code in front of it,
**rewrite it** to say that without the reference; only if what remains is pure narrative about a past edit,
delete it. A comment that explains the code in front of it earns its place — that is the phase's whole thesis.

**The config file's special hazard.** Its comments describe a project graph — dozens of project names,
`testMatch` regexes, dependency chains, setup and teardown names, tag filters and timeouts. Editing a comment
here is safe; editing the value it describes is an E2E-suite-wide behavioural change under CLAUDE.md's cardinal
rule. The behaviour-neutrality prover is the mechanical check, and `yarn typecheck:tests` is the second.

Purpose: remove the largest block of planning narrative in the repo without touching a single value it
describes.
Output: a swept config and a swept shared-test surface, both proven comment-only.
</objective>
