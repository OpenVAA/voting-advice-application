<objective>
Rename the test titles that carry planning references — deliberately, separately, and with the citation
cross-check that makes it safe.

**This plan exists because two governing texts disagree, and the disagreement is resolved by splitting them.**
ROADMAP criterion 5 treats a test title as a legitimately-declined, out-of-scope match — that is precisely
what makes the residue proof in plan `152-05` meaningful. Review comment #4, at the filter package's spec,
says the opposite in terms: *"Never use planning references in test names. Also rem line breaks from
comment."* And that one site has both — the comment above the test and the tag inside the test's own name.

`152-RESEARCH.md` § 6 resolves it, and this plan implements the resolution: **the codemod declines every
title** (preserving criterion 5's proof) and **a separate task with its own gate renames them deliberately**.
Criterion 5's "declined equals out of scope" phrasing governs the *codemod*, not the *phase*. The disposition
was recorded in `152-RESIDUE-REGISTER.md` in plan `152-05` with this plan named as its owner; this is where it
is discharged.

**Renaming a test title is a program-visible change, not a comment edit.** It alters reporter output and
`--grep` selection, and it is the only part of Phase 152 that legitimately changes non-comment bytes in the
swept trees. Two safety properties are therefore proof obligations rather than assumptions:

1. **Suite selection must be unaffected.** The E2E script selects by **tag**, inverting a probe tag, not by
   title — so Playwright project and spec selection is structurally safe. That is verified, not assumed.
2. **CI must not select unit tests by title.** `152-RESEARCH.md` assumption A4 flags this as verified for
   Playwright but **not** verified for any vitest title-selection usage in CI, and says to confirm it before
   this task. Confirming it is Task 1's first action.

**And the citations must be chased.** The E2E run registers under `tests/e2e-runs/` and the planning records
cite test titles verbatim. Renaming a title without checking creates a dangling citation in a document that is
itself evidence. The measured surface is small — roughly **23 anchored occurrences across 20 files** by an
under-counting anchored grep, with the residue TSV as the authoritative queue — so each one can be checked by
hand.

Purpose: close the review comment that criterion 5 could not, without breaking a selection path or leaving a
dangling citation.
Output: a recorded, cross-checked set of title renames and a proof that nothing's selection changed.
</objective>
