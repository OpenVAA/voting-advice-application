Close the phase: give the standing guard its second rule now that the tree is at zero for it, prove the guard
catches, run the cardinal gate, and leave the one out-of-scope drift item filed rather than fixed.

**Why rule 2 arrives now rather than in wave 1.** The guard shipped live in plan `152-01` carrying the
unicode-escape rule, because that rule had exactly one violation in the tree and fixing it took the tree to
zero immediately. The forced-line-break rule could not ship then: D-N1(c) was rejected precisely because *"a
guard that fails on N pre-existing violations cannot be enabled until the sweep runs, so the split does not
work as stated unless the guard ships disabled — which is no guard."* Plan `152-14` has now taken the tree to
zero for that rule at the operator-sanctioned scale, so the rule can go live. **One gate with two rules, in
two commits — never one gate with a disabled rule.**

**The exclusions travel with the rule and are what make the guard keepable.** The five structural categories —
banner rules, list items, JSDoc tags, hanging indents and comment tables — are codified constants in the
script. Per this repo's own no-opt-out principle: there is deliberately no flag, no setting, no exception
roster and no warn-only tier, because an opt-out that can be flipped when the guard is inconvenient makes its
green meaningless. Excusing a case requires editing the file, which is then reviewed as the decision it is.

**The flip is the evidence and the green is not.** That is this repo's own standard, recorded from Phase 147's
paired old/new controls. Two flips close this phase: reintroduce a forced line break and watch `lint:check`
name the site, then revert; and remove the guard's chain link and watch the membership spec fail, then
restore.

**The cardinal gate runs once, here.** CLAUDE.md is unambiguous: a failing E2E test is a cardinal failure, no
task may be marked done while any E2E test is failing, there are no known-flaky exemptions, and a
did-not-run test counts as a failure. Seven judgement plans deferred their suite runs to this point rather
than each running a shared, stateful stack. This phase edited the E2E tree heavily, so the gate is the **full**
suite, not a subset.

Purpose: make the class permanently unreopenable and prove it, then hand a green tree to eleven downstream
phases.
Output: a two-rule live guard, two recorded flips, a filed drift item, and a green cardinal gate.
