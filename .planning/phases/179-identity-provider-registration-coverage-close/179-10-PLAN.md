## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a signed-in caller → `account-access` | the caller's own token decides whose address is changed |
| the function → the auth service | the service role mints email-change tokens and verifies one |
| the function → a mailbox | the mail goes to a typed address the caller chose |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-179-101 | Spoofing | a typed address becoming the account's sign-in identifier without proof, handing the bank-verified account to whoever owns a mistyped mailbox | high | mitigate | the address changes only when the mailed link is opened; no admin update carries an address; conformance assertions (Tasks 1, 3; D-06, Pitfall 1) |
| T-179-102 | Information disclosure | the in-use answer as a bulk oracle | high | mitigate | authenticated caller, identity-provider account on the placeholder only, the per-address and per-caller slot of 179-03 (Tasks 1, 3; D-07) |
| T-179-103 | Elevation of privilege | another user's address changed by forging the caller | high | mitigate | the account is the one the caller's own token names, verified by the auth service; the body names no user (Task 3) |
| T-179-104 | Spoofing | a stranger who receives the mail opens it believing it is theirs | medium | mitigate | the mail is impersonal and tells a recipient who did not register to ignore it; J3 keeps such a link from claiming the stranger's invitations (Task 2; 179-03) |
| T-179-105 | Information disclosure | a token, address or link in the function's log | medium | mitigate | the log receives fixed messages and failure names only; a conformance assertion (Task 3; PROH-179-17) |
| T-179-106 | Denial of service | mail flooding of one address | low | mitigate | one mail per address per minute, shared with the other mails; ten per caller per quarter hour |
| T-179-SC | Tampering | npm/pip/cargo installs | low | accept | this plan installs no package |
</threat_model>
