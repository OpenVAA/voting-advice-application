## Decisions Made

**1. `AdapterSource` and `resolveAdapterConfig` live in `dataProvider.ts`.** A shared home must satisfy two constraints simultaneously — permission to import `@supabase/supabase-js` types, and permission to read `.supabase` — and the four allowlisted selector modules are exactly the set that does. The obvious alternative was measured rather than assumed: a new `src/lib/api/adapterSource.type.ts` containing only the union and its two type imports fires `no-restricted-imports` with *"Supabase packages are banned outside the adapter. Call through the `$lib/api/dataProvider` or `$lib/api/dataWriter` interface instead."* Placing it under `adapters/**` would have moved the `.supabase` read out of the four selector modules, contradicting task 3's own criterion. `dataProvider.ts` is the first of the four and the module the guard's message names first; the other three import both symbols and their factories stay one line each, preserving the uniformity the plan names as the property to keep.

**2. Positive controls beside the isolation assertions.** The four declared `it.todo` cases were filled as two pairs rather than four independent assertions: per vector, one *driver* case asserting the recorded interleaving order and request B's own read-back, and one *isolation* case carrying the RED. The driver cases pass in both runs by design. Without them, a RED could equally well have been an apparatus that never parked request A — the same class of trap wave 1's zone probes were hardened against.

**3. Both `#fetch` counts in one assertion.** `expect([fetchA.calls, fetchB.calls]).toEqual([1, 1])` yields `[0, 2]` in the RED, which is the entire predicted shape in one message. Two `toHaveBeenCalledTimes` assertions would have failed on the first and never recorded that B's spy served two requests.

**4. `resolveAdapterConfig` returns a typed `SupabaseAdapterConfig`.** The tree's existing idiom (`+layout.server.ts:29`) is a typed local, because the mixin's return-type annotation erases the widened `init` override and a fresh object literal carrying `serverClient` would trip the excess-property check. Returning the typed value from a function reuses that idiom without repeating the comment at four sites. This is transitional either way: `157.2-08` moves configuration into the constructor.
