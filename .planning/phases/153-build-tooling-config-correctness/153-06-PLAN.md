## Concurrency: named collision surfaces

**`.gitignore` is touched by no other plan in this phase**, and by neither Phase 152 (comments and
names in `packages/**`, `apps/**`, `tests/**`) nor Phase 163 (`main.yaml`, prettier config,
`apps/supabase/**`).

**⚠ The git index is a shared surface with eleven sibling agents.** This is the only plan in the
phase that mutates the index directly. The mitigations are structural, not procedural: the removal
names exactly four literal paths; no recursive or wildcard form is used; and every status assertion
is path-scoped. An unscoped `git status` in this worktree is *expected* to be dirty at any moment —
the GSD orchestrator and sibling planners write `.planning/` continuously — so an unscoped check
would be both flaky and meaningless here. The `141-NEGATIVE-CONTROL.md` precedent already records
exactly this caveat for a quieter tree; it is more load-bearing now, not less.
