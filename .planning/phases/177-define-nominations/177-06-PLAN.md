<objective>
Plan 6 of 21, wave 6. The two reads the editor needs: which parties or alliances an entity may name, and the id of the parent a nomination already has.

Purpose: an entity's editor cannot read the project's parties through its own policies, and a policy disjunct would return every column of every party. The options are therefore one `SECURITY DEFINER` function with an allow-listed projection, pinned by the census. And without the parent's entity id the cards cannot preselect the party a nomination has, nor tell a listed party from one that is no longer listed.

Output: one red pgTAP commit and one schema commit (`[db]`).
</objective>
