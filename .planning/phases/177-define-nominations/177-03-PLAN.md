## Rulings and deviations carried by this plan

1. **Two triggers over one statement of the matrix** (RESEARCH's primary recommendation): the cells that need no deferral stay in the BEFORE trigger; "has a parent or the typed name" is a deferred constraint trigger. None of the three alternatives OD08-E1 lists as not chosen is taken up.
2. **The row rule fails closed**: it admits a row only when the matrix answers `admitted` or `parent_required`, so an answer of NULL is a refusal.
3. **RESEARCH assumption A5 is tested here** — that pgTAP's `throws_ok` accepts a string of two statements. *What falsifies it:* the assertion errors instead of catching `23514`. *What happens then:* the same assertion is written through a `pg_temp` function that runs the insert and the forcing statement, and the summary says which form the file uses.
4. **The stale sentence in the header of `private.caller_nominated_in_contest`** ("which `validate_nomination` admits") is rewritten by plan 177-05, which changes that function; it is not touched here.
