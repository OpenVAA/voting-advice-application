- `sameNominations(a, b)` — whether two lists of an entity's nominations are the same rows with the same values.

## Rulings and deviations carried by this plan

1. **The compact card is `EntityCard` as it is** — `variant="subcard"`, `headerOnly`, no action — and no component the contract lists as "not touched" is edited.
2. **The keyboard model is the browser's**: radios that share a `name`. The component test asserts the structure that gives it — one name, no `tabindex`, no key handler — and plans 177-17 and 177-20 assert the behaviour in a browser.
3. **A moved card whose stored parent is not among the options** — a case no source describes — keeps that parent only where its entity is of the type the matrix pairs with the card's entity type: the desired nomination then names that entity at the new contest. Otherwise the group starts as a new card's does. It is carried as a flagged assumption of the phase and built as one branch of `parentChoicesOf`.
4. **No E2E run closes this plan**: nothing renders the component or calls the modules.
