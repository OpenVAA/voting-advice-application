## Rulings and deviations carried by this plan

1. **Every change to an existing fixture is additive**, so everything here is committed at once: a new step, a member more in a union an existing step accepts, or an optional argument whose absence leaves the step as it was. A step that would have to change what an existing call asserts is not changed here; it is changed in the plan that changes the surface, in that plan's one commit.
2. **No E2E run closes this plan**: no committed spec calls a new step. The type check and the lint of the tests' project are its gate.
3. **The ids are the UI contract's suggestions taken as written** (U-28 at its recommended option).
