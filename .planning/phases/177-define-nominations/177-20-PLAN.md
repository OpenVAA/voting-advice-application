2. **A control in which the 320 px test is green contradicts the research.** Stop and report; the selector is not edited on a reading that a browser has disproved.
3. **The fix is one class on the label, `whitespace-normal`**, as Phase 174.1 gave the terms-of-use label. Where the name wraps, the checkbox stays centred against its lines, as it does there; no alignment class is added. A voter then sees a long election name on several lines, and the legacy pre-registration page that renders the same selector does too.
4. **Every other test of this plan is expected green on the tree as it stands.** A red scan, or a box outside its card, in the control is a defect of what plans 177-14 to 177-19 built: it is corrected in Task 2's uncommitted set — in the page, or in `EntitySelector` — with a component case where the defect is one a component test can hold, the control is made again under the next suffix with the correction in the tree and named, and the summary records it. A defect that cannot be corrected without editing a component the contract lists as untouched stops the plan with a report.
5. **Flagged assumption — UI: first-paint · The data root on the server.** The steps are built to show a loading frame first (RESEARCH N-2, read and not run in a server render). No scan may rest on that frame: each reach ends on a marker the loaded state alone renders, so the assumption being wrong would change nothing these entries assert.
6. **Flagged assumptions N-5 and N-6** — a long party name inside the entity card's header at 320 px, and whether axe evaluates contrast inside the hidden card — are measured by test 3 and by entry 3. N-6 changes nothing the contract asks: the card is visible, and the dataset's parties carry colours on which the initials pass.
7. **The pre-commit run is a full default run**: the selector is rendered by the voter's election page, which specs outside the permutation chain read.
8. **The visual project is not part of a default run and its baselines are captures of the CI image.** The base dataset's election names fit on one line, so no baseline is expected to move; whether one did is read from the phase's CI evidence by plan 177-21.
9. **The backstop row is not a test of this plan.** The whole editor by keyboard and with a screen reader is a person's read; plan 177-21 files it. What a browser can hold of it — one tab stop, the arrow keys, focus after each navigation — is the two tests named above.
