<the_contract>
**One object of `p_nominations`.**

| Key | Value | Meaning |
|---|---|---|
| `id` | a uuid, or absent | present: this object describes that existing nomination of the entity; absent: a new nomination |
| `election_id` | a uuid | required |
| `constituency_id` | a uuid | required; with `id`, a value other than the stored one is a move |
| `election_symbol` | a string or null | trimmed; blank is no symbol; more than 50 characters is refused |
| `parent` | an object with `kind` | `none` — no parent and no typed name; `entity` with `entity_type` and `entity_id` — link that entity's nomination at the contest; `other` with `name` — store the typed name, link nothing; `keep` — leave the row's parent and typed name as they are |

A key the function does not name is not read.

**Refusals of the argument**, each SQLSTATE `22023` with a message beginning `set_entity_nominations: ` and, for an item, naming `p_nominations[<index>]` in the indexing `create_invitations` uses: the entity type is not candidate or organization, or an argument is NULL; not an array; an item that is not an object; `election_id` or `constituency_id` missing or not an id; `id` not an id, named twice, or naming no nomination of this entity in the function's reach; an `id` whose `election_id` is not the stored row's; `election_symbol` neither a string nor null, or longer than 50 characters after trimming; `parent` missing, not an object or of an unknown `kind`; `entity` whose `entity_type` is not the type the caller's type is paired with (an organization for a candidate, an alliance for an organization) or whose `entity_id` is not an id; `other` whose `name` is not a string, is blank after trimming or is longer than 100 characters; `keep` on an object with no `id` or on a move; two objects without `id` in one election; an object without `id` in an election in which an object with `id` stays.

**The reach.** The nominations of the entity that the caller can read, whose `election_round` is their election's `current_round`, in an election for which `public.nomination_shape_rule` answers anything but `refused` for the entity's type.

**The order.** A caller that does not hold `nomination.edit` on the entity is refused first, `42501`. Then: delete the in-reach rows the set does not name and the old row of every move; update the kept rows whose symbol, parent or typed name differs from what is stored; insert the new rows and the new row of every move, each with no parent, then link. For `entity`: ask `private.nomination_id_in_contest` for the parent's nomination at the contest and the election's current round; where it answers NULL, insert the parent's row — project, the organization or alliance id, election, constituency, round, and nothing else — and ask again; then repoint. After every UPDATE and DELETE the row count is read, and a shortfall raises `42501` with the message `set_entity_nominations: a nomination could not be written; nominations are locked or the rows are no longer the caller's`. Last, the constraint `nominations_parent_required` is forced and set back.

**The answer.** `{"inserted": n, "updated": n, "deleted": n, "unchanged": n, "parents_created": n}`; a move counts once under `deleted` and once under `inserted`.

**What passes through unchanged**, each raised by a guard that already exists: `23514` from the two election-type rules, `23503` from the parent foreign key, `P0001` from the cap, `42501` from a policy's check or the column trigger, `23505` from the uniqueness key.
</the_contract>

3. **A symbol longer than 50 characters is refused, not cut** (item P-06).
4. **Two simultaneous placeholder inserts are not caught** (item P-08): the second save is refused whole on the uniqueness key and a retry links the row that now exists. No exception block is written around the placeholder insert.
5. **The key names of one object are this phase's and become Phase 177.1's contract** (OD08-F3 (a)); they are the table of `<the_contract>`.
6. **A move leaves the old contest's placeholder parent behind** (RESEARCH Pitfall 11): it is not the caller's row and the caller may not delete it. It is stated in the function's header and in the cap's todo, which plan 177-21 files.
