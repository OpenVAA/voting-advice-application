| `shape` | candidate | organization | faction | alliance |
|---|---|---|---|---|
| `organization_list` | organization, required | alliance, optional | organization, required | none |
| `organization_list_and_independents` | organization, optional | alliance, optional | organization, required | none |
| `candidate_only` | none | none (not nominable) | none (not nominable) | none (not nominable) |
| `organization_only` | none (not nominable) | alliance, optional | none (not nominable) | none |

"None" is an empty `types` with `required` false. A faction is never a member of `types`: the database also admits a faction's nomination as a candidate's parent, which no screen offers, and the comparison table says so.
