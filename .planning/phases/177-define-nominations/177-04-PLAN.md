## Rulings and deviations carried by this plan

1. **No E2E run closes this plan.** No application code writes a nomination as an entity's editor before plan 177-09, and no spec reads a symbol an editor wrote. The schema block's closing full run is plan 177-07's.

3. **`authenticated` already holds the table-level DELETE privilege** (RESEARCH RQ-2, read from the applied database). One assertion pins it, so that a later change of the grants reddens here and not in a browser.
