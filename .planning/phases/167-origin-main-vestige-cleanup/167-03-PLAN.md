<objective>
Declare `js-yaml` (and its types) in `@openvaa/llm`, the package that imports it, so the package stops resolving it
only through hoisting. This is a correctness fix — the packages are headed for npm publishing and an undeclared
import fails for consumers — and it lands as its own commit ③ `fix[deps]` (D-13, D-24 ③).

Purpose: D-01 fact 12. `packages/llm/src/prompts/promptRegistry.ts` has `import * as yaml from 'js-yaml'` but
`packages/llm/package.json` does not declare it; today tsup inlines the library into `dist/index.js` because tsup
externalises exactly `dependencies` + `peerDependencies`. Declaring it makes the import external, which is both the
fix and the observable proof of it.

Output: commit ③ (`packages/llm/package.json` + `yarn.lock`). The removals from `question-info` and
`argument-condensation` follow in 167-04 (commit ④).
