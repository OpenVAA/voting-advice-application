## ⚠ Nothing in this plan may run until `142.1-02`'s last revert and last post-gate

Two independent reasons, both measured:

1. **The unit gate.** `turbo.json:9-12` declares `test:unit` with `dependsOn: ["build"]`. A root
   `turbo run test:unit` taken while an injection is live would build the injected tree and hand it to
   every dependent — whole-suite contamination, not per-file collateral.

   `decryptAndVerifyIdToken.ts` — **authentication material**. A suite run overlapping an injection
   window would go red for a manufactured reason and, for these files, would be a security event as
   well as a measurement error. This is 139 § 3.1's standing prohibition, carried verbatim.
