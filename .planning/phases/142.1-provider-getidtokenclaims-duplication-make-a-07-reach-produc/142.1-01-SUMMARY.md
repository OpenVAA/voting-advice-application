## Decisions Made

- **All eight OLD halves are GREEN (blind), 8 of 8.** Not one of the eight guards saw the regression its own title promises to catch. This is exactly what the phase needed the pre-collapse tree for, and it is now unavailable to measure again once `142.1-02` deletes those guards.
- **Rows 5/6 claim neither the stale snapshot nor the import-time crash for their OLD half.** The plan required recording *which* surface was observed. On the pre-collapse tree, **neither** was — no assertion in either provider file reads the result of `getIdTokenClaims`, so the frozen snapshot had nothing to surface against. The row says so, and says why that absence is itself the finding rather than a null result.
- **The A-11 relabel table became prose.** Rendered as a markdown table, its own rows (`| 4 |`, `| 5 |`) counted as register rows and its cell quoting 142's original column-5 label placed a borrowed value inside a table row — tripping two of Task 1's acceptance gates simultaneously. Converting it to bullets preserves the content and lets the gates mean what they were written to mean.
- **The ledger carries a per-row measurement-cell table under each `### Row N` heading.** This makes `pending` countable per *cell* rather than per row (a markdown row is one line, so a row-level grep can never see four unfilled cells), and gives each row somewhere to carry narrative — the zero-delta check, the snapshot-vs-crash disclosure, the divergence block — that a table cell has no room for.
