## Caveats — where a claimed bar is weaker than the code that closes the threat

**Caveat A — T-142.1-09.** The stated criterion is "`providers/index.ts` does not reference the
core", which is literally true but does not address the threat: the core **is** transitively
reachable from that barrel via `idura.ts` / `signicat.ts`, which import `$lib/server/constants`
themselves. What actually closes it is SvelteKit's transitive `$lib/server` guard (green `yarn build`)
plus all four barrel importers being server-only files. Both verified. The threat is closed; the
criterion as written would not have caught a violation.

**Caveat B — T-142.1-05.** Ledger rows 5 and 6 omit the per-row `measured at HEAD … loop iteration N
of 8` header the other six carry. Not a repudiation gap — the authoritative row-register table
records `0a3a5aef8` / `0e0ddcca9` for both — but a cosmetic inconsistency in the one document whose
whole purpose is reproducibility.
