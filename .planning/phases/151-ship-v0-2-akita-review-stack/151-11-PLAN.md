## The loop (D-04, D-06, D-07, D-19) — as established in plan 151-09

Sweep the slice → land fixes on `feat-gsd-roadmap` first → cut the slice from the fixed tip → run
the remaining-slices catch-all → open the PR for the slice below. A fix touching an already-cut
slice means re-cutting from that slice upward; it is unopened, so this is one script invocation.

**PD-02 is armed for this slice.** If any fix adds or edits a file under the migrations directory,
that fix is `[BLOCKING]`: apply it locally with a full database reset, run the SQL linter and the
pgTAP suite against the reset database, and do not cut the slice until both are green. Build and
type checks pass without an applied migration, so nothing else in the pipeline catches it. Record
`migrations_added` in the disposition frontmatter whether the count is zero or not.
