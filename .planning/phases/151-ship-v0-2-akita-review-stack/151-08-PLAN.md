## The written rule the residue agents apply (Claude's Discretion, D-16 / D-13)

A residue item is resolved by exactly one of four verdicts. No fifth verdict exists.

1. **REWRITE** — the item is a planning reference in a position where removing it changes no
   behaviour and no test identity. Collapse it to the short pointer form, or delete it if nothing
   survives. Applies to: comment-shaped lines the classifier missed, Markdown prose in shipped
   source, and SQL or shell comments.
2. **REWRITE-WITH-CARE** — the item is a planning reference in a **runtime user-visible string** or
   an ESLint rule message. The reference must go — a shipped product must not tell a user about an
   internal decision ID — but the surrounding message must still read as a complete sentence and the
   string's role must not change. Rewrite the message, do not merely excise the token. Every such
   rewrite is additionally recorded as a checklist item 3 and item 10 finding in
   `151-DISPOSITION.md`, because a planning reference reaching a user is a defect, not just untidiness.
3. **KEEP** — the item is a **test identity**. Test titles are matched by name in CI logs, in the
   coverage plan, and in the project's own failure records; rewriting one silently orphans every
   reference to it. Keep it, record the reason. This is a deliberate, recorded exception to
   criterion 3, not an oversight.
4. **KEEP-VERSION** — the item is a genuine tool, package or platform version that merely looks like
   a milestone tag. Keep it. Pitfall 6 measured this class: the pattern matches the package manager
   version, the Node version, the Playwright image tag and the framework major version as readily as
   a milestone tag, and D-14 authorises stripping milestone tags only.

For D-13's second clause — a comment the code makes redundant — the rule is narrow **because D-13
forbids restructuring**: delete a comment only when the identifier it explains already says the same
thing, in the same words, on the same or the adjacent line. If making the comment unnecessary would
require renaming or restructuring, the comment **stays**. That is the explicit boundary D-13 draws,
and this late against the cardinal E2E rule it is drawn on purpose.
