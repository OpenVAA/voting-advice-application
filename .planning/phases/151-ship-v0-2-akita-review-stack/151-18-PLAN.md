## E2E execution prerequisites — binding, from project memory

The full-suite gate is not "run the command". It requires, in this order:

1. **A clean database.** Reset from migrations, so nothing depends on an incrementally-mutated local
   state. If plan 151-11 added a migration, this is also PD-02's required verification.
2. **Exactly one fresh dev server on the expected port.** A stale server steals the port and the
   suite then measures the wrong tree. There is no Playwright-managed web server in this project;
   the dev server is started separately and deliberately.
3. **The preflight passes.** It asserts the served application's HTTP response proves the page came
   from *this* checkout. There is no flag and no environment variable that skips it, and a preflight
   failure aborts the run before any spec body executes.

A "did not run" test counts as a failure, not a pass — cascade failures from an upstream dependency
are failures.
