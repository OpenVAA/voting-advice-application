## The loop (D-04, D-06, D-07, D-19) — as established in plan 151-09

Sweep → fix on `feat-gsd-roadmap` first → cut from the fixed tip → remaining-slices catch-all →
open the PR for the slice below. PD-01 governs any suite regression; PD-02 does not apply to this
pathspec.

**One extra constraint here.** A fix to a test is a fix to the phase's own gate. Any change to a
spec must be justified against what it asserts, not only against whether it passes — a spec edited
until it goes green is the exact failure the cardinal rule exists to prevent. The project's standing
acceptance rule applies: prove the guard fails before claiming it guards.
