## Decision PD-03 — what happens if the baseline is red

If `yarn lint:check` or `yarn format:check` is red at baseline:

1. Enumerate every failure (rule id, file, line) in `151-BASELINE.md` under a
   `## Pre-existing failures` heading.
2. Those failures are **outside D-05's fix bar** by default — they are pre-existing debt, not
   findings introduced by the v0.2 body of work, and repairing them would inflate the diff the
   stack exists to make reviewable.
3. **Exception:** a pre-existing failure that a slice sweep independently surfaces under checklist
   item 3 or 4 *is* in scope for that slice, and is dispositioned there with its baseline status
   cited as evidence.
4. Each pre-existing failure gets a row in `151-DISPOSITION.md` with verdict
   `**DEFERRED** — pre-existing at baseline`, evidence = the baseline command output plus the
   file and line. Never a blank cell, never an implicit pass.
