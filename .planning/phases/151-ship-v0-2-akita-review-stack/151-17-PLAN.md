## Why the secret scan is the highest-value security action in this phase

`151-RESEARCH.md` § Security Domain states it directly: **this control is not on the code review
checklist, because the checklist assumes a pull request someone reads.** Every other slice in this
stack gets human eyes. This one, by design, does not.

The scan is therefore a **blocking precondition to pushing this slice**, not a follow-up. Its result
is recorded in the disposition matrix as a first-class row even though no checklist item asks for it.
