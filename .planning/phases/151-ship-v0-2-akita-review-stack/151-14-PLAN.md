<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser client → Supabase API via the adapter layer | Every data read and write in the voter and candidate apps crosses here; the adapter's session handling is what route guards depend on. |
| server-side render → client hydration | The adapter's fetch-carrying initialiser is what keeps server-rendered requests correctly scoped; getting it wrong leaks or drops session context. |
| context accessor → component reactivity | A destructured reactive accessor silently freezes at its init value. No lint rule catches it; the project has a documented incident. |
