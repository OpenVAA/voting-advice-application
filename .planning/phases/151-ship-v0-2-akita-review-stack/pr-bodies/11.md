## Read this first — the stack contract

This is one PR in a **review-only stack of twelve**, cut from the v0.2 body of work so that it can
actually be read. Four things follow, all deliberate:

1. **Individual PRs need not build, lint, or pass tests. Only the whole matters.** The stack slices one
   large final state into twelve diffs of similar nature. Intermediate states are not required to be
   working states.
2. **The stack's final state is byte-identical to the development branch's final state.** The twelve
   slices are a re-partition of the same tree, not a re-implementation.
3. **Because of (2), the stack does not need to be merged.** It exists to be read. Merging the
   development branch or the stack produces the identical tree.
4. **Review comments need not be implemented inside the stack.** Fixes can land on a separate branch.

**No file is shown to you twice in two different content versions.**

Three things that make this more than a formality, each of which changed the result:

- **One scanner is not a scan.** TruffleHog found 2 distinct JWTs; the independent sweep found **4**,
  adding Supabase demo `anon` and `service_role` tokens that no detector flagged. Both proved to be
  published public constants — established by **recomputing their HMAC** against Supabase's documented

- **A working-tree grep is not a census when the content includes archives.** The one remediated
  credential existed in **32 places, 28 of them inside Playwright trace archives**; a working-tree grep
  reported 4. Both archives were rebuilt member-by-member with an equal-length replacement so the trace
  JSON and its recorded offsets stay valid.

Also measured: **zero** cloud hostnames (`*.supabase.co/.in/.net`) across all 2,325 files, and **zero**
JWK private key components.
