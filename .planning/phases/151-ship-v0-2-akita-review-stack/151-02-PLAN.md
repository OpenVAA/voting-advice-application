  <action>
Create `slice-overlap-matrix.sh`, which takes a slice-definition file (one line per slice:
`<slice-id><TAB><pathspec…>`) plus a `PARENT` and `TARGET` ref pair.

For each slice, compute its file set with
`git -c diff.renameLimit=20000 diff --name-only -z --no-renames "$PARENT" "$TARGET" -- <pathspec…>`,
split on NUL (Pitfall 2 — one tracked path contains a space), and write it sorted to a scratch file.
Then print an N×N matrix whose cell `(i,j)` is `|slice_i ∩ slice_j|` computed with `comm -12`.

Print the diagonal as each slice's own file count. Exit non-zero if any off-diagonal cell is
non-zero — for a path-partitioned stack the correct off-diagonal value is exactly 0, because each
file belongs to exactly one slice's pathspec. Any non-zero off-diagonal cell is a partition bug and
must name both slice IDs and the first three shared paths.

Add a `--union` mode printing the union file count and comparing it against
`git diff --name-only "$PARENT" "$TARGET" | wc -l`; a shortfall is the same defect the catch-all
tripwire catches, detected earlier and more cheaply.

Follow the `audit-skill-drift.sh` tail: unconditional matrix print, then remediation prose, then
counter-derived `exit 1`.
