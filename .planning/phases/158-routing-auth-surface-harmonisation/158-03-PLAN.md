## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser ↔ OIDC provider | The state, nonce and code-verifier cookies carry the CSRF and PKCE bindings for the whole bank-authentication exchange. |
| client-side writer → server-side reader | One cookie is written by a browser component and read by two server endpoints; a name mismatch across that boundary silently breaks PKCE. |
| Supabase SSR bridge → cookie jar | The bridge writes names this app does not choose and must not be captured by the app's declaration. |
