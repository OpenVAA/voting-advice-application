<objective>
OB-5's remaining three deliverables: make a refused response impossible to mistake for a value
anywhere in the adapter stack, reject an invalid job identifier before it reaches the pipeline,
and prove both with round trips whose red half is the real defect rather than a synthetic one.

Purpose: the ruling calls this the same fail-loudly class an earlier ruling named on the write
path — a degrader that turns a failure into a value the caller cannot tell from success. The
plan that precedes this one measured the mechanism at this HEAD and the operator answered on the
arm; this plan applies that answer, in full, to a seam every adapter consumer in the application
passes through.

Output: a seam that cannot convert a refusal into a value, a parsing helper whose own contract
says so, a job-identifier guard in both job features, three recorded round trips, and a
recompiled census.
</objective>
