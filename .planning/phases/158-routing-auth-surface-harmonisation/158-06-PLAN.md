<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| email link → callback endpoint | An invite or recovery link is a bearer credential arriving from outside; the callback exchanges it for a session. |
| backend redirect allowlist → browser | The allowlist is the control that stops an attacker steering an authentication redirect to a host they control. |
| repo configuration → production configuration | The local allowlist is in the repo; the production allowlist is not, and only one of them is under version control. |
