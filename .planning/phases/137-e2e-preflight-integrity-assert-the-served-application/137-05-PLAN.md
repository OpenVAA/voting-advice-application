<objective>
Gate the phase on evidence, not on inference.

Two things remain after plans 01-04, and neither can be skipped.

**The cardinal rule.** CLAUDE.md's E2E Hard Rule makes any failing E2E test a cardinal failure, and a
"did not run" counts as a failure. This phase changed the harness itself and inserted a gate that
aborts every run when it fires — which makes a flaky preflight maximally severe, since a single
spurious abort turns ~97 projects into "did not run". A full green `yarn test:e2e` is therefore not a
formality here; it is the only evidence that the gate is correct rather than merely strict.

**The CI-only gap.** Research could not obtain CI timing data — the newest workflow run is
2026-07-26, on a different branch. The 120 s CI poll ceiling is justified as *budget-preserving*
(exactly what the deleted loop already granted), not as a measurement. And the wait-loop removal's
failure mode exists only on a runner: after plan 02, `yarn test:e2e` starts immediately after the
backgrounded frontend, and the preflight's poll is the sole thing absorbing cold-start. That cannot
be reproduced locally. This plan therefore verifies it by pushing and observing, and says so plainly
rather than implying local proof.

Purpose: close the phase with an observation for every success criterion, including the one no local
run can produce.
Output: an appended CI-observation section in `137-NEGATIVE-CONTROL.md`.
</objective>
