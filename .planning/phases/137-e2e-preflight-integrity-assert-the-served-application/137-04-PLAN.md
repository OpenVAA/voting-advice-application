**The correction the docs must carry.** `FRONTEND_PORT` is a half-wired escape hatch. Measured by
controlled experiment: Playwright reads it from the root `.env` via `dotenv.config()`, but the dev
server does not — `apps/frontend/vite.config.ts` reads `process.env` at config-evaluation time,
before any `.env` loading. Writing the variable into `.env` therefore points Playwright at a port the
dev server never took, and the new preflight will correctly fail on it with a message the operator
will read as a preflight bug. Every doc that mentions the hatch must say: export it in the shell for
**both** commands (RESEARCH QUAL-2). This sits squarely inside criterion 4's "`FRONTEND_PORT`'s role
as the alternate-port escape hatch is documented".
