<objective>
Build the served-application preflight and wire it as the harness's unskippable gate.

This is the phase's load-bearing plan: it creates the assertion that a page under test came from
*this* checkout, and the enforcement point that makes it impossible to omit. Everything else in
Phase 137 either closes the drift at source (plan 02), proves this plan works (plan 03), documents
it (plan 04), or gates the phase on it (plan 05).

checkout's Vite dev server" as a legitimate named failure), D-03 (everything derived at runtime),
D-04 (`globalSetup` as the enforcement point), D-06 (poll then fail), D-07 (no bypass), and D-09
(failure-message contents). Satisfies INTEG-04 and INTEG-05.

Purpose: a false green from a foreign dev server is undetectable after the fact. Every later phase
in milestone v2.15 rests on this gate.

`tests/playwright.config.ts`.
