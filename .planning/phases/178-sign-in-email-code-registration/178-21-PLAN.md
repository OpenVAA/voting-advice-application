## Rulings and deviations carried by this plan

1. **Where the entries live is item U-26 ★, a declared departure from D-22's letter.** Three places hold the twenty entries: this spec (fourteen), the closed-project spec (three, plans 178-16 and 178-18) and the shared scan spec (three, plan 178-22).
2. **The spec seeds its own two codes in its hooks; it has no setup project.** A registration code is a credential and is not written to a file for another project to read. The execution rules' names for a setup pair of this spec are therefore not used; the spec's project depends on the base dataset's setup alone.
3. **The entries seed candidates** — the reserved rows `test-e2e-base-ca-scan-open` and `test-e2e-base-ca-scan-used` — each with no nomination, so seeding makes nothing public under either form of the seeding function.
4. **States not scanned are those the UI contract lists with their reason** — the answers-locked sentence, the notices, the no-profile sentence, a group error, the "count ended" state and the transient ones — each a pairing another entry scans, each asserted by a spec or a unit case.
