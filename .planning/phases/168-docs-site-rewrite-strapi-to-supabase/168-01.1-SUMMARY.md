## Operator decision (checkpoint resolution)

The first executor stopped at a `blocking-human` decision. D-15 requires every docs lint error to be fixed at source, with no
suppression and no rule weakening. That collided with D-07's component freeze, because 4 errors sat in `ResearchQuote.svelte` (3)
and `ReferenceList.svelte` (1). **Ruling (genuine, from the operator via the orchestrator, 2026-10-02): Option B, "Fix at source,
re-anchor freeze".** How it was applied:

1. **Fixes:** `eslint --fix` plus `prettier --write`. The changes are sorted value imports, `type Snippet` moved to a top-level
   `import type`, and `string[]` changed to `Array<string>` (×2). No markup, style or logic line changed, and `Author.svelte` was not touched.
2. **Render proof:** The docs build is an SPA with no prerendered HTML, so the proof used SSR from a fresh `vite dev` of all six
   ResearchQuote pages, with UUIDs normalised. The before/after comparison was 6/6 byte-identical. Two "before" runs were also
   identical, which shows the snapshot is deterministic. As a sensitivity control, a one-character markup change turned 6/6 red.
3. **Re-anchor:** A new `--component-base <rev>` option compares `COMPONENT_PATHS` to that revision, while spans stay on `--base`. The
   anchor is the Task 1 code commit `6090476cc`, recorded in `gate-evidence/component-base-rev.txt`.
4. **Controls:** Each control went red and then green. Changing one character in `Author.svelte` failed, and so did one character in
   `ResearchQuote.svelte`; both were reported as `changed since component base`. Changing one character inside quote block 1 of
   `preparing/matching` failed against the original base `0ec229dfe` (`block 1 differs at character 611`).
5. **Recorded in:** `168-DOCS-AUDIT.md`, under § Decisions (the ruling, the D-07 scope exception and the re-anchor), and in
   `gate-evidence/168-01.1-lint.md` § 8.

**The single documented span-gate invocation from now on, for plans 168-02..08 and Phase 169** (run from the repo root):


## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] `.svelte-kit` ignored in the docs ESLint config**
- **Found during:** Task 1 (first executor).
- **Issue:** Once the config loaded, `eslint .` crashed on the `.svelte-kit/output` build output, because ESLint 9 does not read `.gitignore`.
- **Fix:** Added `{ ignores: ['.svelte-kit'] }`, which is the same ignore the frontend config has. No rule changed.
- **Commit:** `6090476cc`

**2. [Rule 1 - Bug] `move-generated.ts` guard lost its `api/` exemption**
- **Found during:** Task 2, Step 4.
- **Issue:** `!existsSync(srcPath) && !src.startsWith('api/')` lets a missing `api/` source pass the guard. With the new destination clear, that would wipe the destination, which breaks the plan's "a missing source never wipes a destination" truth.
- **Fix:** The guard is now `!existsSync(srcPath)`. No target starts with `api/`.
- **Commit:** `04b772ff1`

**3. [Rule 3 - Blocking] TypeDoc lines in `apps/docs/README.md` and a TypeDoc comment in `generate-all-docs-and-validate.ts`**
- **Found during:** Task 2, Step 1.
- **Issue:** The acceptance grep `git grep -i typedoc -- apps/docs package.json` covers both files, and the action's narrower grep covers the script.
- **Fix:** Removed 3 README lines that describe config files that do not exist, and reworded the script's header comment to list what it actually runs. The rest of the README is still 168-07's to rewrite.
- **Commit:** `04b772ff1`

**4. [Rule 3 - Blocking] Audit logs stored as `.txt`**
- **Issue:** The root `.gitignore` ignores `*.log`, and force-adding is not allowed.
- **Fix:** Committed the logs as `168-01.1-audit-before.txt` and `168-01.1-audit-after.txt`, and noted this in `168-01.1-audit-deps.md`.
- **Commit:** `ac92fd712`

**5. [Interpretation] Baseline rows deleted although their `via` reads `markdown-it@14.1.0`, not `typedoc@…`**
- The `via` field records only the immediate parent. The old lockfile shows `linkify-it` ← `markdown-it` ← `typedoc` as the only chain, and the two ids are exactly the ones the removal made stale.
- The three rows whose `via` literally reads `typedoc@0.28.15` (minimatch) are not stale and were kept. Their now-outdated `via` text is left for the next reviewed baseline update.

**6. [Checkpoint-driven] Lint-only edits to two frozen components and the `--component-base` option**
- Applied as the operator ruled; see above.
- **Commit:** `6090476cc`
