## Pattern Assignments

### Content pages `+page.md` (content, static)

**Analogs:** plain page `apps/docs/src/routes/(content)/developers-guide/auto-documentation/+page.md`; component-using page `apps/docs/src/routes/(content)/publishers-guide/what-are-vaas/intro/+page.md`.

Conventions observed:
- No frontmatter. File starts with the H1 (or with a `<script lang="ts">` block when components are used). The H1 is the nav title source unless `fixedTitle: true` (generate-navigation-config.ts).
- Layout is applied globally via mdsvex `layout: { _: './src/lib/layouts/MdLayout.svelte' }` (svelte.config.js) — pages do not import a layout.
- Internal links are absolute, URL-form, without `(content)`: `[Requirements](/developers-guide/development/requirements)`. validate-links rewrites relative to absolute.
- GitHub source links: `https://github.com/OpenVAA/voting-advice-application/(blob|tree)/main/<tracked path>` — target must be `git ls-files`-tracked (D-10 check).
- Remove the legacy banner line `> **Note:** Parts of this page reference the legacy Strapi backend ...` (top of e.g. `developers-guide/troubleshooting/+page.md`, `deployment/+page.md`) when a page is rewritten.

Component import block (what-are-vaas/intro/+page.md, top of file):
```svelte
<script lang="ts">
  import ReferenceList from '$lib/components/ReferenceList.svelte';
  import Author from '$lib/components/Author.svelte';
</script>

# What are VAAs and why are they useful?
```
Anchors: heading ids come from `rehype-slug` with `smartypants: true` (curly quotes change slugs — the broken `#docker-error-no-space-left-on-device-errordocker-...` anchor in troubleshooting is an example). Never edit `<ResearchQuote>` spans (D-07); Prettier must not reflow them (Pitfall 5).

### `apps/docs/scripts/validate-links.ts` + `scripts/utils/links.ts` (CLI, file-I/O batch)

**Analog:** itself. Keep the skeleton:
- Imports: `fs/promises`, `path`, `fileURLToPath`; helpers from `./utils/links` and `./utils/routes` (`findMarkdownFiles`).
- `const ROUTES_DIR = path.join(__dirname, '../src/routes');`
- `main()` accumulates into a `ValidationResult` (`totalFiles`, `totalLinks`, `fixedLinks`, `brokenLinks: Array<BrokenLink>`), calls `printSummary`, `process.exit(1)` on any broken; bottom: `main().catch((error) => { console.error(...); process.exit(1); });`
- `validateFile` writes back via `fs.writeFile` only when relative links were rewritten — `--check` mode must skip this write path entirely.
- `BrokenLink { file, link: MarkdownLink, reason }` — reuse for every new finding type (svelte href, nav route, anchor, stub, GitHub path) so `printSummary` groups them by file.

Extension points in `utils/links.ts`:
- `checkPathExists` — currently accepts a file or a dir with `+page.md` only; extend to `+page.svelte` and `+page.ts` (stub; but in `--check` a link targeting a stub is an error).
- `checkLinkExists` — already retries under layout groups `(…)`; reuse for nav routes and svelte hrefs.
- `resolveLink` strips `#hash` — anchor check must keep the hash separately.
- `extractMarkdownLinks` handles `[t](url)` and `[t](<url>)`; reuse for GitHub URL extraction (per-line regex).
- `isInternalLink` / `isHashLink` — reuse.

Anchor oracle and GitHub path check: use RESEARCH § Code Examples ("Anchor-id oracle", "GitHub source-path check") — `mdsvex.compile` with `rehypePlugins: [rehypeSlug], smartypants: true`; tracked set from `git ls-files` plus prefix dirs, `decodeURIComponent`.

### Script CLI conventions (all `apps/docs/scripts/*.ts`)
**Source:** `apps/docs/scripts/validate-links.ts`
`#!/usr/bin/env tsx` shebang; JSDoc header; `__dirname` from `fileURLToPath(import.meta.url)`; `console.info` for output (not `console.log`); `Array<T>` generic syntax; non-zero `process.exit(1)` on findings; invoked via package script `tsx scripts/<name>.ts`. `generate-all-docs-and-validate.ts` runs sub-scripts through `runCommand`/`execAsync`, which rethrows on non-zero exit.

### Gate reading
Read exit status directly, never through a pipe (memory: piping lint hid violations).
