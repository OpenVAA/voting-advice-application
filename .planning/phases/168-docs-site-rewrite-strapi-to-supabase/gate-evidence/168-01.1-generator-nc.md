## The fix

In `moveGenerated`'s loop over `COPY_TARGETS`, after the skip guard and before `moveAndTransformDir`:

```ts
    // A missing source keeps its committed destination
    if (!existsSync(srcPath)) {
      console.warn(`Warning: Source path not found: ${srcPath}`);
      continue;
    }

    // Clear the destination so pages for deleted sources do not survive
    await rm(destPath, { recursive: true, force: true });
```

The guard lost its `&& !src.startsWith('api/')` exemption (Rule 2, see the SUMMARY): with the clear in place, an `api/` target with a
missing source would have passed the guard and been wiped. No `COPY_TARGETS` entry starts with `api/` today; the exemption was TypeDoc
residue.
