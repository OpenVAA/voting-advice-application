`--extract-dir $PHASE_DIR/gate-evidence` wrote `rq-base.json` and `rq-head.json` to
`apps/docs/.planning/phases/…/gate-evidence/` (an untracked directory) on the first run. Both files were byte-identical to
the committed ones (`cmp` exit 0). The stray directory was deleted and gate 3 was re-run with the absolute path above
(exit 0, no change to the committed files). Without `--extract-dir` the gate writes nothing, so the Phase 169 handoff
command does not need it.
