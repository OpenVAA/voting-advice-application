## Approach

The build sequence is verification-first, ADR-second, types-third, frontend-fourth, fixtures-fifth, cells-sixth, cleanup-seventh, integration-eighth. Wave 3 (cell migrations T5-T8) runs SERIALLY (4 atomic commits one per T) rather than in parallel — git's hunk-merge across the same `voter-mega-journey.spec.ts` file is fragile, and operator-mandated rigidity is more important than wall-clock speed.

A single composite "pre-flight verification" task resolves the 5 RESEARCH open questions via file-reads and performs the 1 atomic baseV1 edit (Boolean `filterable: true` → `false`). **Wave 1 — T3 ADR + landing (Tasks 2-4):**

**Wave 3 — T5/T6/T7/T8 cell migrations (Tasks 7a-7d serial):**
