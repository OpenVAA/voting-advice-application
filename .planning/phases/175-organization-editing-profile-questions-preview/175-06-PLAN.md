## Rulings and deviations carried by this plan

1. **Orchestrator ruling 1.** U-03, U-08, U-09, U-23, U-27 and U-28 stand at their recommended option and are built as the UI contract writes them.
2. **The UI contract's one unresolved consideration is carried as a stated assumption.** *Adding `color` as the fifteenth member of `InputProps` is assumed to keep `yarn workspace @openvaa/frontend check` green.* The type file already works around a "union too complex" limit at fourteen. **What falsifies it:** `svelte-check` reporting that error, or a type that widens to `any`, once the member is added. **What happens then:** the control is built as a sibling component of `Input` in the same directory, with the markup and the state contract of § *S3* unchanged and the same test file pointed at it; the summary says so, and plan 175-09 imports the sibling.
3. **The hex grammar the kind accepts is narrower than the parser's.** A typed value is a colour when it is `#` or no `#` followed by three or six hexadecimal digits; functional `rgb` notation, which `parseColorString` also reads, is an invalid entry here. The value the kind emits is always lowercase `#rrggbb`, which is what the database's check of plan 175-03 stores.
4. **Generated component pages are not regenerated here.** The docstrings change in this plan; `yarn workspace @openvaa/docs generate:docs` runs once, in plan 175-13.
5. **This plan closes on gate rows and one slice, not a full run.** The slice is the existing contestant axe scans, which read every changed attribute on the candidate's pages; the full default run of plan 175-08 is this plan's boundary proof.

6. **A subset gate run is observed refused as the full set** (plan check, W9): after this plan's six-row run, the `gates` verdict asked for it without `--rows` must exit non-zero.
