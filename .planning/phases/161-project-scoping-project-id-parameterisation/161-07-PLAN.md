## Decision record for this plan

### DR-18 — What counts as the proof, and what does not

The verdict for each run is taken from the run directory's machine-readable summary and provenance
record, not from console impressions:

- `counts.failed == 0` **and** `counts.didNotRun == 0` **and** `counts.flaky == 0`
- `preflight-fail: 0` **and** `preflight-ok` at least 1 in `provenance.txt`
- the run's `exit` file records 0

Both runs must satisfy all three. The last full gate run on record was 150 tests in 10.7 minutes, so
budget roughly 25 to 30 minutes of wall clock for the pair plus setup.

**If either run is not green:** it is a real defect. Diagnose and fix it, then re-take **both** runs
from scratch into fresh run directories — a code change between run one and run two invalidates the
pair, because the pair's claim is about two runs of the same code. Record every discarded attempt in
the SUMMARY with its counts and the diagnosis, so the record shows what happened rather than only the
successful attempt.

### DR-19 — Run one keeps its reset; only run two proves the claim

Run one is taken **with** the reset, once, to establish a known start. Run two is taken with
`--no-db-reset`, and is the run that discharges the criterion: it proves the suite does not require the
reset, starting from whatever run one left behind. Taking run one without a reset as well would prove
the same thing more strongly but would make a failure ambiguous between the phase's changes and
accumulated prior state — and under the cardinal rule an ambiguous failure costs a full re-take.

### DR-20 — The disk budget is asserted, not assumed

Measured while planning: 22 GiB free of 926 GiB at 98% capacity — below the 23 GiB the research
recorded a day earlier, so headroom is still falling. Two full-suite runs have already been lost to
exhausted disk in an earlier phase, and under the cardinal rule a voided run must be re-taken in full.
Headroom is therefore measured **before** the pair is committed to. Reclaiming space is a host-level
operation an agent cannot perform, so a shortfall is escalated to the operator rather than worked
around. `tests/e2e-runs/` must not be deleted: the phase registers cite it, run directories are under
two megabytes each, and the space is in the container layer.
