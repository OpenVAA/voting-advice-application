<objective>
Turn the enumeration plan 161-15 performed by hand into a committed artifact that performs itself, so the
ninth review of this guard cannot find a tenth spelling by reading harder than the eighth did.

Purpose: `161-VERIFICATION.md`'s third `missing:` item asks for the module docblock's two universal-reach
sentences to be corrected to the true residual. The reason they were false is not carelessness — it is
that nothing measured them, so a sentence written in good faith at the moment of a closure went stale the
moment the next spelling was found. Correcting the prose without closing that gap produces a sentence
that is true today and unverified tomorrow. This plan makes the reach paragraph a checked claim: every
position is enumerated from the declaration itself, every position is mutated and required to matter,
every cell of the canonical call shape must carry a written disposition, and every residual named in the
docblock is pinned by the assertion that measures it.

Output: three new helpers and three new describe blocks in the gate spec — a line-anchored declaration
slicer that can fail, a per-position mutation harness with one measured exemption, and a generated
punctuator-by-position matrix bridged to the mutation enumeration — plus the corrected module docblock,
three follow-up items filed per D-N2, and the probe paths added to `.gitignore`.
</objective>

**The vocabulary is complete.** Stripping all three token forms from each of the seven declarations
leaves no escaped question mark in any of them, so every optional-punctuator admission the guard contains
is an enumerated cell.

**The cross product holds, and is what the matrix asserts.** 100 generated variants — both spellings at
every operator position of every matcher's canonical call shape, chained and unchained — all match, and
every committed near miss still does not.

**Cells that are not `matches`, measured rather than assumed.** `this.supabase.schema('public')['from']('x')`
is reported by SCHEMA_HOP_RE. `this.supabase['from']('x')` and `this.supabase.rest['from']('x')` are

boundary and invocation checks — so the same three spellings at that address are UNREPORTED. And
`this.supabase/* c */.from('x')` matches nothing anywhere: the matchers admit whitespace around a
punctuator, not trivia.

**Timing, because this harness spawns the guard many times.** `--self-test` skips the 550-file walk and
completes in about 50 ms, so nineteen mutants plus one unmutated control cost roughly a second in total —
comfortably inside a per-test timeout when each cell is its own test case.

**One hazard already in the tree.** Neither existing vacuity probe path is ignored by git, so a failed run
that skipped its cleanup leaves an executable copy of the guard in `scripts/`. This plan adds a third

**One cell that the bridge in task 3 cannot bridge, named here so it is declared rather than discovered.**
`CLIENT_BINDING_RE` carries one enumerated cell belonging to a negative lookahead rather than to a link of
the canonical call shape — the branch that admits the optional punctuator in order to EXCLUDE it. A
lookahead position has no spelling in the shape it rejects, so it is declared as an excluded count with a
written reason instead of being matched to a link. Exactly one matcher has one today.

<assumption_delta_decision>
**The noun that is now primary:** the **(matcher x operator-position x punctuator) cell**.

**Decision: `add-alongside`** — the same decision plan 161-15 records, and this plan is the half that makes
it real. The named matchers stay exactly what the guard executes and what a reader greps for; the cell
becomes an enumerated noun beside them, DERIVED from the declarations rather than authored next to them,
so the two cannot disagree.

**Rationale:** eight reviews of this guard have each found one cell, and none could find an empty one,
because nothing enumerated the axes. Enumerating them is the difference between a closure and the next
closure.

**What would force a promote:** the moment a matcher needs a position the canonical-shape template cannot
represent, the template stops being able to bridge to the declaration, and the cell matrix has to become
the source the declarations are generated from. Deliberately not done now: generating the regular
expressions from a table would cost the vacuity probes their verbatim pin and the reader their grep.

**The contract test the delta invites is this plan itself.** The bridge assertion in task 3 is the precise
encoding of the generalized intent: it goes red both when a position is admitted without proof and when a
position of the call shape is left unadmitted — the two directions of the singular assumption this phase
kept reintroducing.
</assumption_delta_decision>
