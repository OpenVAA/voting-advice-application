### DR-11 — The caller-supplied `project_id` is validated, not trusted

Measured: the function parses `project_id` out of the request body and lets it win over configuration;
its own docblock states the endpoint is served with JWT verification disabled and is reachable with the
publishable key; and the only in-tree caller,
`apps/frontend/src/routes/api/candidate/preregister/+server.ts`, does **not** send the field. So today
the field is purely an attacker affordance: an unauthenticated caller can direct a self-registration
into any project uuid it knows.

This phase is the moment the function gains a server-side statement of which project it serves, so the
fix is one equality check and it lands here rather than being filed. Removing the field entirely is
**not** chosen — that would silently change the HTTP contract; refusing a mismatch with a fixed 400 is
observable and testable.

**Reversibility: reversible.** A body-field validation is a code-level change with no migration and no
published contract beyond an error status this endpoint's only caller never triggers.

### DR-12 — Local edge-runtime env wiring is attempted here, and filed if the mechanism does not hold

Measured: `apps/supabase/supabase/config.toml` carries a commented-out `[edge_runtime.secrets]` block
with a `secret_key = "env(SECRET_VALUE)"` example, there is no `apps/supabase/supabase/functions/.env`,
and the environment variable is unset locally today — which is why the function currently falls
through to the hardcoded constant without anyone noticing.

Once the fallback is removed, an unwired local edge runtime makes `identity-callback` fail on every
invocation. Blast radius is bounded and known: the `bank-auth` and `bank-auth-journey` Playwright
projects are gated behind `PLAYWRIGHT_BANK_AUTH` and are excluded from the default `yarn test:e2e`
run, so this cannot break the twice-in-a-row proof in plan `161-07`. It **would** break the Idura
runbook, so task 2 wires it and verifies by invocation. The mechanism claim is low-confidence
(`161-RESEARCH.md` assumption A4), so task 2 carries an explicit failure branch: if the wiring does not
take effect, revert the `config.toml` edit, file the todo, and add the environment prefix to the
runbook's documented command instead.
