## Decision record for this plan

### DR-16 — Criterion 4's grep is a **class** grep over live documents only

The literal string the roadmap quotes — "reset the DB first" — appears nowhere in the repository, so a
literal grep would pass vacuously. The criterion is delivered as a **class** grep: the reset command
appearing as a stated precondition of running the E2E suite. Scope: live documents only —
`CLAUDE.md`, `tests/README.md`, `tests/IDURA-TEST-RUNBOOK.md`. Archived material under
`.planning/milestones/**` is the historical record and is deliberately out of scope, following the
scoping precedent already set for a comparable grep in this repository.

Sites that stay: the reset documented as a **command** in `CLAUDE.md`'s command map, in
`apps/supabase/README.md`'s schema instructions, and in `packages/dev-seed/README.md`'s seeding map.
Only the statements that make it an E2E **precondition** are retired.

### DR-17 — The retirement is gated, not just performed

A committed test asserts the class invariant over the three live documents. This is the difference
between a document that is correct today and a document that stays correct. The test lives in
`packages/dev-seed/tests/` beside the existing repository-meta gates and therefore runs in
`yarn test:unit`, not in `lint:check` — the guard added in plan `161-01` is the `lint:check`
addition for this phase, and appending a second link for a documentation assertion would be
disproportionate.
