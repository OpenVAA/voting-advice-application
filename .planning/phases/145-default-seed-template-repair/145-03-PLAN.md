<objective>

<relationship_to_d04>
## ⚠ This probe does not override D-04 — read this before assuming it does

D-04 locked the **standing regression guard** for TMPL-03 as the anon-client assertion inside
`default-template.integration.test.ts`, and explicitly **rejected** "a Playwright spec seeding
`default` mid-suite", for two stated reasons: it would contaminate the shared database, and it would
put a cardinal-rule gate at risk for a check the integration job makes more cheaply.

Neither reason reaches this probe:

- It does **not** seed mid-suite. It is seeded **out of band**, before the run, exactly as the five
  existing probes are.
- It is **not in the gate**. Every test in it carries `@probe`, and the root `test:e2e` script appends
  `--grep-invert @probe`. It cannot fail the cardinal gate because it never runs in it.

The standing guard remains `145-02`'s anon assertion. This probe is the **criterion-1 evidence
instrument** — the thing that turns "verified in the running app, before and after" from a claim into
two exit codes and two screenshots. If a reviewer reads it as a second standing guard, that reading is
wrong and this section is the correction.
</relationship_to_d04>
