<objective>
Reconcile the `default` template's `external_id` idiom with the conventions the repository already
has, and write down the places where it deliberately does not match `e2e/base`.

TMPL-04 was re-scoped from "constant naming" — the constants were measured and are already consistent
— to the `external_id` idiom, and then narrowed again by measurement: the eleven class-based
generators already use one scheme, and the template agrees with it on five of seven hand-authored
collections. **Two typecodes diverge.** This plan changes those two, sweeps the prose that names them,
and records the divergence from `e2e/base` that criterion 4 permits.

Output: a template with one identifier idiom, a documented divergence, a green suite, and ledger row
`T1`.
</objective>
