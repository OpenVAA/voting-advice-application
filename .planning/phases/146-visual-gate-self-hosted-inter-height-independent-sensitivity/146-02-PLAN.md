<objective>
Prove, by observation, that the harness written in `146-01` actually reaches Playwright and clears the
served-application gate from inside the pinned container — and that the font-egress blackhole is live
at both `curl` and browser level.

Purpose: `tests/tests/support/preflight.ts:429-444` requires strict absolute-path equality between the
frontend root the **host** dev server echoes and the one the test process derives from its own
location. The v2.14 recipe's `-v "$PWD":/work -w /work` fails that comparison and aborts **every**
run this phase needs, with exit 1 before any spec body and a message about a *"DIFFERENT checkout"* —
which reads like a wrong-server problem rather than a mount problem (M-12, Pitfall 5). Everything
downstream — the blindness half, the noise matrix, the cap, the font delta, the re-baseline, the six
determinism runs — is blocked behind this one run succeeding. Prove it once, record it, then build on
it.

The egress controls sit here for the same reason in miniature: D-11 says the block must be proven live
**before** the suite runs behind it, because a green suite behind an unproven block proves nothing.
The criterion-4 run in `146-08` gets its own immediately-preceding `curl` control (`EG1-CURL`); these
two rows prove the **mechanism**, so that a failure in `146-08` is unambiguously about the app rather
than about the flag.

Output: three filled register rows, a complete `Machine` provenance bullet, and a recorded host
dev-server identity that later plans depend on staying continuously up.
</objective>
