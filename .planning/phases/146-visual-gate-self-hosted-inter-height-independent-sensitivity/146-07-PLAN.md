<objective>
Re-capture the four baselines against the configuration and the rendering this phase produced, prove
they compare green afterwards, give the run-4 anomaly a bounded and falsifiable chance to reappear, and
record the production app's own request list.

Purpose: VGATE-06 is the single expensive step both halves of this phase were landed together for.
VGATE-01/02/03 changed what the gate tolerates; VGATE-04/05 changed what it renders. Either alone would
have left an intermediate baseline set matching neither the old nor the final rendering. This plan
produces the final one.

Two things make it more than a mechanical `-u`. First, the re-baseline is taken **behind the egress
block**, so the pixels it commits provably came from same-origin Inter — turning research's most
dangerous failure mode from a discipline problem into an impossibility. Second, it is verified by a
subsequent **non-updating** run: baselines that have never been compared against are a recording, not a
gate.

Output: four re-captured PNGs, one green clean-tree comparison, up to three recorded reproduction
attempts, and one production-build request list.
</objective>

<polarity>
## ⚠ In `146-07`, the re-baseline run is the one step that cannot be un-noticed

- **Before writing:** `guardThirdPartyFonts` must be green and `document.fonts.size` must be at least 1
  in the same session. If either is not, **stop**. A `--update-snapshots=all` run behind a broken font
  path writes fallback-font pixels into the committed directory and every subsequent gate in this
  phase, and in CI, will pass against them.
- **`G0-CLEAN`** is expected **green**. A red here after a successful re-baseline means the capture is
  not reproducible run-to-run at the derived cap, which is a cap problem or a noise problem — diagnose
  it, do not re-run `-u` until it goes away.
- **`D16-A1`…`A3`** have **no expected outcome**. Reproducing the anomaly is a good result (it names
  the failing test, which v2.14 lost). Not reproducing it is also a legitimate result, provided it is
  recorded as *still unexplained* with its power stated. The only illegitimate result is a closure by
  absence of reproduction.
- **`PT1-PRODTRACE`** is expected to show **zero third-party font requests**. It is not expected to show
  zero occurrences of `fonts.googleapis.com` in the build output — those survive by design, and the row
  must say so, or the next reader will find a regression that is a string literal.
</polarity>
