<objective>
Measure the two things the cap cannot be chosen without: the gate's **blindness**, re-observed on the
untouched configuration, and the four baselines' **run-to-run noise**, from forty observations rather
than from a guess.

Purpose: ROADMAP criterion 2 does not accept the v2.14 record as evidence — it requires the same
injection re-run against the old configuration *in the same container* to re-observe the miss. And
VGATE-03 does not accept a threshold that works; it requires one that can be **re-derived**. Only the
`candidate-preview` pair has any prior noise data at all (0 px, both v2.14 runs); the voter pair's
noise has never been measured, and that gap is this phase's reason for existing.

This plan is still ledger-first: the last plan in the phase that writes zero product bytes. `146-04`
lands the cap, and it can only do so honestly because the blindness half is already on the record in a
commit that precedes it.

Output: two filled register rows, a fully populated 40-cell matrix, and a cap value derived in the open
by an arithmetic rule that was written down before the numbers existed.
</objective>

## ⚠ In `146-03`, a PASS is the finding and a FAIL is the health check

- `B1-OLD` — `voter-results-desktop` is expected to **PASS** with the injection live. Its outcome token
  is `**The green IS the finding, not the health.**` A desktop *failure* here would mean the old gate
  was never blind and the phase's premise is wrong: **stop and diagnose** before touching anything.
- `B2-OLD` — `voter-results-mobile` is expected to **FAIL**, at roughly 19,545 px. This failure is the
  proof that the injection actually reached the served application. A mobile **pass** almost certainly
  means Vite served a stale module rather than that the gate is sensitive — restart the host dev
  server, re-run, and **record the restart in the row**, because `146-07`'s D-16 control depends on
  knowing every restart that happened.
- The 40 noise cells — a `0` is a perfectly good measurement, and roughly half the matrix is expected
  to be zeros. An empty cell is not a measurement at all.

Nothing in this plan is allowed to make the gate stricter. The cap is computed here and installed in
`146-04`.
</polarity>
