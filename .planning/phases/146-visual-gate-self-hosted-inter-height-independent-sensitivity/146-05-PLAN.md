<objective>
Make the application serve its own Inter, and make a broken same-origin path fail **by name** rather
than as a whole-page pixel diff.

Purpose: VGATE-05 is a privacy change with a testing dividend, not the other way round. Every page load
of this voting advice application currently discloses the visitor's IP and user-agent to a third-party
font host; VGATE-04 then makes that same dependency a hard requirement of a **blocking** CI job. Both
go away by moving 119 KB of already-licensed bytes into `static/fonts/` and changing one default string.

The one honest unknown is deliberate and is **not** resolved here. Google serves a **variable** face for
the two-weight `css2` request; the vendored files are the corresponding **static** instances, and
whether FreeType's variable-font instancing and static rasterisation agree at these sizes is
**unmeasured**. `146-06` measures it. This plan's job is to land the change and leave the old baselines
in place so that measurement is still possible.

Ordering note: this plan follows `146-04` rather than running beside it, deliberately. The font delta
must be measured against the cap **already in force**, or *"did the pixels move?"* and *"did the verdict
move?"* are confounded.

Output: seven new files under `apps/frontend/static/fonts/`, one changed default string, one new guard
in the visual spec — and a served application observed to have taken all of it.
</objective>

<polarity>
## ⚠ `146-05` does not re-baseline, and its visual run is expected to be RED

After the font lands, the committed baselines were captured against **Google-served variable Inter**
and the app now renders **self-hosted static Inter**. A visual run at this point may well fail, and
that failure is not a defect — it is the delta `146-06` exists to measure.

- **Do not** reach for `--update-snapshots` to make it green. The re-baseline is `146-07`, after the
  delta is recorded, and using bare `-u` would additionally skip within-tolerance images.
- **Do** treat a green run as informative too: if all four baselines still pass, the rasterisation was
  neutral within the cap, and that is the finding `146-06` will record with numbers.

The one thing that must be green in this plan is the **served application's own response**:
`/fonts/inter.css` returns 200, the four woff2 paths return 200, and the served HTML carries no Google
Fonts stylesheet link. That is a health check, not a pixel claim.
</polarity>
