## ⚠ Nothing in this plan may run until the phase's last revert and last post-gate

Every injection in Phases 142-01 through 142-05 must be reverted and post-gated before **any** command in
this plan is issued. Two independent reasons, both measured:

1. **The unit gate.** `turbo.json` declares `test:unit` with `dependsOn: ["build"]`. A root
   `turbo run test:unit` taken while an injection is live under any `packages/*/src` would rebuild that
   package's `dist/` and hand the injected build to every dependent — a whole-suite contamination, not a
   per-file collateral. `packages/data`'s F20-5 injection is exactly that shape.
2. **The E2E gates.** Phase 142 transiently breaks `apps/frontend/src/routes/api/oidc/authorize/+server.ts`
   and `.../getIdTokenClaims.ts` — **authentication material**. A suite run overlapping an injection
   window would go red for a manufactured reason and, for the auth files, would be a security event as
   well as a measurement error. This is 139 § 3.1's standing prohibition, carried verbatim.

