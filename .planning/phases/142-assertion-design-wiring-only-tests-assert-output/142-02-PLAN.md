**This package's specific hazard, and why the `cd` is not optional.**
`packages/argument-condensation/src/core/condensation/condenser.ts:198` writes

inside this package** (`.gitignore:3`). Running from the repository root leaves an untracked directory
and fails the post-gate for a reason that has nothing to do with the injection. Every run in this plan
starts from `packages/argument-condensation`.

**No `yarn build` and no cache-busting anywhere** (A-01): all four test files import source specifiers,
and `test:unit` is declared `"cache": false`.
