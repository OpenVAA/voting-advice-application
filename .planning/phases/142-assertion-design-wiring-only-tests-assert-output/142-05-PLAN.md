`argument-condensation`, `frontend` and `dev-seed` — a whole-suite contamination, not a per-file
collateral. **Task 3's injections must never be live during a root run.** In-package
`npx vitest run` only. The root `yarn test:unit` gate belongs to `142-06`, on a clean tree.

**A `git mv` is a working-tree change.** Task 1 renames a file, which the scoped pre-gate will see.
