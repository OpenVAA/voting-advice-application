## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser cookies → SvelteKit hooks → Supabase Auth | ssr encodes/decodes the session; the adapter writes auth cookies |
| IdP JWE/JWT → `identity-callback` | jose decrypts and verifies bank-auth tokens |
| function input → SMTP | `send-email` builds messages with nodemailer |
| Deno edge runtime → npm registry | `npm:` imports resolve at function boot, outside `yarn.lock` |
