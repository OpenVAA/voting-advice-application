  --ecosystem npm <names>` on every package name new to `yarn.lock`. `SLOP` stops the plan. `SUS` for any reason

  checkpoint. A direct package new to the repository needs its box ticked in `169-LEGITIMACY-APPROVALS.md`.

  `git log`; `.planning` commits are separate.

  at run time.
