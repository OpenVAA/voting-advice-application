<objective>
Prove the determinism breach is real, on unfixed code, before anything is fixed.

This plan builds the observation harness the whole phase depends on: a purpose-built in-suite
template that actually reaches both wall-clock date sites, the anti-vacuity assertions that keep it
honest, and the two-clock run whose differing output is the negative control REVIEW-SEED-02 demands
(decision D-C2: a vitest guard using `vi.setSystemTime` at two dates months apart, explicitly not
`libfaketime` and explicitly not fix-only).

**This plan MUST land before the fix plan.** The ordering is the whole point of criterion 2: a wave
that ships the reference-date edit and the guard together destroys the ability to observe the drift
and makes the criterion unprovable. The dependency is expressed as `154-01` in the fix plan's
`depends_on`.

Purpose: turn "the contract is false across days" from a claim into a recorded measurement.
Output: three committed tests, all green on the unfixed tree, plus the recorded pre-fix drift values
in the plan SUMMARY.

**Why the leading task is a tracer:** the control template is the thinnest end-to-end path through
every layer this phase modifies — template validation, `buildCtx`, the elections generator, the
candidates generator, the answers emitter, and the pipeline's emitted rows. Proving that one path
end-to-end first is what makes every later assertion in the phase non-vacuous.
</objective>
