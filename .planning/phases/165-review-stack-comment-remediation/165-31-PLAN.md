<objective>
First third of the maintainer's repo-wide style rule (#880 `Header.svelte`, C-4106826598, D-10:
"Inline as tailwind classes as much as possible. Do this for all style blocks in components"), and
the whole of #880 `ImagePart.svelte` (C-4106608766: "Inline these classes") — the input family and
the small base components.

Purpose: `<style>` blocks that `@apply` utilities hide styling from the markup; D-10 keeps CSS only
where it is genuinely needed. Tailwind v4 generates a class only when its syntax is valid, so an
inlined class that is mistyped produces no rule and no error — hence a compiled-CSS check.

Output: eight components restyled, a phase-local compiled-class checker.
</objective>
