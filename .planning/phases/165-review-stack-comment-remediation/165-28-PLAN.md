<objective>
Stop anonymous and authenticated callers from manufacturing orphan feedback rows (#877
`107-feedback.sql`, C-4080520167, security-relevant): require `project_id` at insert time while
keeping `ON DELETE SET NULL` as the only path to a NULL project.

Purpose: research reproduced it live in a rolled-back transaction — `SET LOCAL ROLE anon; INSERT INTO
public.feedback (rating, description) VALUES (5, 'probe orphan')` succeeded with `project_id IS
NULL`, and the "global admin reads orphans" disjunct then exposes such rows. A trigger enforces the
requirement without editing the INSERT policies' `WITH CHECK (true)`, whose text the content-policy
suite asserts.

Output: a trigger, a negative-control pgTAP file, regenerated artifacts, a green full gate.
</objective>
