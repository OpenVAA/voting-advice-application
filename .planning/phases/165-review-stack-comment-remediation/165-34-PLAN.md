The phase's closing hygiene sweep (D-04, ROADMAP criterion 3): prove that every file the branch
changes satisfies the comment-hygiene rules, reconcile the per-plan read records against a second,
independent read, review every allowlist entry, and disposition the code-review checklist over the

allowlist row can hide a real reference, and a check that only agrees with itself proves little —
