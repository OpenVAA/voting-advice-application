<objective>
Stage A wiring (per CONTEXT.md D-90-10): extend the dynamic-settings surface with an optional `i18n.supportedLocales` override so perm templates (Plans 90-03 + 90-04) can restrict the user-facing locale list at runtime. Without this, the localisation-negative perm cannot assert "no language selector" (Paraglide's compile-time locales array always contains the full superset en/fi/sv/da/et/fr/lb, and `staticSettings.supportedLocales` is hardcoded — Phase 74 D-04 deferred single-locale testing for this exact reason).

Purpose: Unblock PERM-L10N-NEG-01..03 assertions in Plan 90-03 by enabling per-perm runtime locale-count control. Preserve all existing translation bundles and Paraglide compile-time behaviour.
Output: 1 type extension (`DynamicSettings.i18n.supportedLocales?`) + 1 init.ts read-path change (override-or-default) + 1 i18nContext propagation tweak.
</objective>
