# Phase 179.1 Plan 05: The Answers Lock in the Database Summary

**While a project's `access.answersLocked` holds, the database now refuses every entity-scope write of an entity's own editor:**
- **Rows:** the four self-update policies and the four entity-scope nomination policies carry `private.project_answers_locked`.
- **Files:** `storage_path_can` refuses an entity-scope write.
- **Functions:** `upsert_answers` and `set_entity_nominations` refuse with SQLSTATE `42501` and `<function>: answers are locked in this project`.

**No project-scope rule reads the lock, so project editors and project admins keep writing.**
