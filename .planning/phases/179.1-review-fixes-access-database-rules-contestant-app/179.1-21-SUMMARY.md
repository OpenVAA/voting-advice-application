# Phase 179.1 Plan 21: one sign-in component, one way to a password Summary

**Both sign-in screens now render `PasswordSignIn` with two links: "Forgot Password?" and, where `signInLinkOffered` allows it, "I have not set a password yet". Both lead to `/contestant/forgot-password`. On the email sign-in screen each link carries the address typed so far as `?email=`. The forgot-password page puts that address in its field when it is created, so its own request covers a user who never set a password. The two screens' own buttons that asked for a sign-in link are gone, with their handlers and info lines. The entry pages no longer set their own `max-w-md`; the layout sets the width.**
