## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| browser → database (RLS) | entity editors, project editors/admins and anonymous voters reach tables, RPCs and storage through PostgREST under row-level security | answers, profile fields, nominations, images, invitations, grants |
| mailed link → frontend server | a link in a mail is fetched (possibly by scanners) and confirmed on the confirm page | one-time token hash, link type, `next` target |
| frontend server → Edge Functions | `account-access` and `identity-callback` act with the service role on the frontend's or user's request | addresses, identity-provider claims, entity and grant creation |
| identity provider → `identity-callback` | OIDC sign-in completes into a find-or-create of entity and grant | provider subject, name, locale |
| test harness → shared stack / CI | E2E wrapper, mock issuer, key server, evidence branches | test keys, run evidence |

### Audit notes (non-blocking)

1. **T-179.1-38: one claim in the register cell is wrong.** The cell says the parity script's self-test runs in `lint:check`. It does not: `lint:check` runs `yarn assert:hosted-settings-parity`, which calls the gate, and nothing in `package.json` or `.github/` runs `--self-test` (confirmed by the orchestrator). It was run once by hand in plan 13 (66 cases, exit 0). The drift threat stays covered by the gate itself, whose `redirectProblems()` rejects `**`, a trailing `*`, a wrong number of paths and a path that matches no local entry. Follow-up: wire `--self-test` into `lint:check`, or correct the cell.
2. **T-179.1-47 and -48 rely on `sanitizeHtml` (DOMPurify).** Plan 32's dependency audit reports critical advisory GHSA-cg2g-xh64-v4q7 against `dompurify@3.4.16`, tracked in `.planning/todos/pending/2026-10-29-179.1-dependency-audit-sixteen-new-advisories.md`. -48 also escapes the address with `escapeHtml` before interpolation. Upgrade before ship.
3. **T-179.1-63:** the register says "two-letter"; `uiLocalesFor` accepts 2 or 3 letters (`/^[a-z]{2,3}$/`). Still a closed shape that cannot carry injected content.
