## Rulings carried by this plan

1. **The cause, confirmed.** The diagnosis compiled a copy with `, ` in the 91 variant keys of the 14 multi-selector messages: `infoQuestionsLeftPlural === "one" && opinionQuestionsLeftPlural === "one"`, 70 of 70 key returns down to 1 (French `many`). The space separator was never valid in any 4.x of the plugin. Confirmed again here only by the guard's red and green.
2. **The ICU exact matches, restored from their source.** The 17-01 conversion turned ICU `=0` and `=1` into the plural categories `zero` and `one`. No locale of the seven produces `zero`, and French `one` covers 0 and 1, so French 0 reads the singular. The originals are in `git show 6b3be8ea5^:apps/frontend/src/lib/i18n/translations/<locale>/<file>.json`, with `candidateApp.` where the catalogue now says `contestantApp.` (read at planning: the logout modal's `itemsLeft` was `{infoQuestionsLeft, plural, =1 {is still one item} other {are still # items}}`). For each variant message: where its original used `=N`, the selector becomes the input itself, matched as `=N`, and the `local … : plural` declaration goes when nothing else uses it; where the original used plural categories, they stay; a message with no ICU original keeps its categories. Every variant message with a numeric selector ends in a `*` catch-all, which takes in French `many` and any category no variant names. Paraglide 2.25.4 checks variants in order and a catch-all returns unconditionally, so `*` comes last (read in `compile-message.js`), and an input match compiles to `(i.x === 0 || i.x === "0")` (read in `match-literals.js`).
3. **The guard reads the compiled index.** `vitest.config.ts` aliases `$lib/paraglide/messages` to a stub, so the guard imports `src/lib/paraglide/messages/_index.js` by file path. That file exports each message under its key and takes `{ locale }`. It is generated, by the build (the turbo `test:unit` depends on `build`) or by `yarn workspace @openvaa/frontend paraglide:compile`. A guard that cannot find it fails and names that command: a check that cannot look refuses.
4. **The plugin pinned.** `apps/frontend/project.inlang/settings.json` loads `https://cdn.jsdelivr.net/npm/@inlang/plugin-message-format@4/dist/index.js`, which jsdelivr resolves to 4.6.0 today (measured in the diagnosis), network-first through `@inlang/sdk`. It becomes `@4.6.0`, the version the comma form was verified with. `plugin-m-function-matcher@2` is not named by the ruling and stays.
5. **The copy checkpoint is the round's only one.** Its items cover plans 56 to 66, so the operator answers once and the later plans run unattended. The answers are recorded in this plan's summary, § *The copy decisions*, which plans 58 and 64 read.
6. **No E2E test is added.** The guard is the gate the ruling asks for, over every message and locale. The close shows whether any committed test read a wording that now changes, such as a count of 0 that now reads its `=0` text: such a test is corrected in its own commit, with a ledger row.
