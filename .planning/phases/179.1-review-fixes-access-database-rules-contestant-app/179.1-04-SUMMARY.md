# Phase 179.1 Plan 04: The Constituency Rule in the Nomination Trigger Summary

**`validate_nomination` now refuses, for every writer, a nomination whose constituency is no constituency of its election, with SQLSTATE 23514. That covers an entity's editor, a project admin, the service role and `bulk_import`. An UPDATE is judged only when it changes the election or the constituency, so a stored nomination whose constituency was unlinked later can still be edited. `set_entity_nominations` no longer carries its own copy of the rule, and a pin shows that it reports a shape fault before an id fault.**

## Accomplishments

### Migration 00013 and the rule

- **Where the rule sits.** It is in `public.validate_nomination` in `schema/011-validation-functions.sql`. It comes after the shape rule's `nomination_shape_rule(` and before `IF NEW.parent_nomination_id IS NULL`. The verify block's index check confirms this order in both the schema file and the migration.
- **What it judges.** It judges every INSERT. It judges an UPDATE only when `election_id` or `constituency_id` changes. The INSERT/UPDATE choice is made in an `IF` before `OLD` is read.
- **What it checks.** An `EXISTS` over `election_constituency_groups` joined to `constituency_group_constituencies`.
- **The refusal.** `Nomination constituency % is no constituency of its election %`, `check_violation`.
- **The comments.** The function's header and the file's index line state the rule.
- **The migration.** `00013_nomination_constituency_rule.sql` is the header and the function as the schema file has them, byte for byte. It has sha256 `31be42d9884b8b6de01e70da6be5e0be99b7177883b3801b638d13afb1a7b736`.

### Migration 00014 and the single statement

- **The function.** In `set_entity_nominations` (`schema/503-entity-rpcs.sql`), the `IF v_is_new AND NOT EXISTS (…)` block and its message are gone. `v_is_new` stays, because the keep check and the write plan read it.
- **The header.** Its paragraph now says that the trigger judges every new or moved nomination.
- **The migration.** `00014_set_entity_nominations_constituency_once.sql` re-creates the function with the schema text. Its sha256 is `9b6a2ee10191b68ff0d52f3ef1a17afebe98c5180f2e516f484c5c412df20984`. Its function body differs from 00007's only by the twelve removed lines, as checked by `diff`.
