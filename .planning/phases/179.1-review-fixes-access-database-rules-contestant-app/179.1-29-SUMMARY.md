## Decisions Made

- **No `kit.prerender.entries`:** the build showed that the default `'*'` enumerates every stub route (rulings item 1).
- **A separate refactor commit:** a vitest case for `validateStubs` needs the function exported and able to read a fixture routes directory. Making that behaviour-neutral change in its own `refactor` commit kept the red commit to tests only. Stub targets in the fixture still resolve against the site's real routes, so the fixture stub redirects to `/developers-guide/about-these-docs`.
- **What the parser accepts:** exactly one line `export const prerender = true` (the semicolon is optional) and no other `prerender` token. This refuses `prerender = false`, a duplicate, and a commented-out mention. It runs after the redirect checks, so the existing redirect error messages are unchanged.
