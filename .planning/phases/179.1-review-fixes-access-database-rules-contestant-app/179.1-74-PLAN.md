## Rulings carried by this plan

1. **The precondition.** `$U/179.1-70-decisions.txt` records C1 (approved or edited, and `179.1-70-approved-strings.json` committed as approved), C2 `a` and C3 `a`. A C2 or C3 answered `b` stops the plan before Task 1, for the planner to revise it.
2. **The reasons.** `ContestantLoginError` in `$contestant/utils/loginError` gains `loggedOutAutomatically` and `loggedOutElsewhere`, mapped to `common.loggedOutAutomatically` and `common.loggedOutElsewhere`; the map's docblock names each. The page keeps reading `errorMessage` from the address bar, and only a reason the map holds as its own member has a message (as now). This plan builds the first reason's path; plan 75 builds the paths that put either reason on the address bar.
3. **The server's sign-out, read from the marker.** The hook signs a run-out request out and writes `logout-pending=passed` into the same response; the gate redirects a protected request to the login page; the browser's next request, the login page's, carries the marker, and the page's settlement removes it only after that navigation (`afterNavigate` and `onMount` in the root layout). So the login page's `load` (`routes/contestant/login/+page.server.ts`), which returns nothing today, answers `{ signedOutReason: 'loggedOutAutomatically' }` when `cookies.get(COOKIE.logoutPending)` reads `LOGOUT_DEADLINE_SETTLED`, and an empty object otherwise; it reads no session (`PROH-179.1-49`). The page shows the notice for the address bar's reason when there is one, else for the load's. The load's docblock says both of what it is for.
4. **The announcement.** The notice keeps `role="alert"`, which a screen reader announces when the element is inserted after a client-side navigation; one present in a document's first HTML is not announced by every reader. So the heading `<h1 tabindex="-1">`, which `focusNavigationTarget` focuses after every navigation, the first one of a document included, carries `aria-describedby` naming the notice's id while a notice is shown. A browser test asserts the heading's accessible description holds the sentence; what VoiceOver, NVDA and TalkBack say is not claimed (rule 17).
5. **C3's limit.** A tab that reaches the login page after another tab has met the server's sign-out finds no marker and shows no reason; recorded for the operator's list, as C3 decided.
