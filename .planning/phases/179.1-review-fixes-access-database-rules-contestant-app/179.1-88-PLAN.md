1. **The module (A1),** `apps/frontend/src/lib/auth/logoutAnnouncement.ts`, with rule 21's names, each TSDoc'd.
   - `announceLogout(kind)` posts the word `kind` on the channel. It uses the channel this document listens on while one is open, and otherwise one opened for the message and closed at once, as now. It does nothing outside the browser or where `BroadcastChannel` is undefined, and throws nothing.
   - The listener records two times by `Date.now()`. A `start` sets the time of the outstanding start. An `end` sets the time of the last end and clears the outstanding start. A message of any other value changes nothing.
   - `heardLogoutAnnouncement()` is `true` when an outstanding `start` is no more than `LOGOUT_IN_FLIGHT_CAP_MS` old, or the last `end` no more than `LOGOUT_ANNOUNCEMENT_WINDOW_MS` old. An elapsed time below 0, from a clock set back, counts as neither.
   - The module's header says what the pair is for. The listening tab's `SIGNED_OUT` comes after the announcing tab's requests, so the window follows the Log out rather than starting before it. The cap stops a tab closed during its Log out from holding the window open.
