# Phase 179.1 Plan 58: What a reader hears over an unsaved edit and on a failed sign-out Summary

**Over an unsaved edit the Contestant App's logout dialog is now named by the existing `common.logoutUnsavedChanges` sentence, under the visible title `Log out`, and its hidden description leaves that sentence out; the failed sign-out's message in both apps is titled `error.general`, and an `Alert` with no actions hides its corner ✕ from assistive technology and the tab order, so it exposes one Close.**

## For the operator's reading

What a reader now meets, as the browser computes it:

- **The logout modal over an unsaved edit** (Contestant App): the dialog's accessible name is `You have unsaved changes. They will be lost if you log out.` (C3 a, the existing `common.logoutUnsavedChanges`). Its visible title stays `Log Out`. The description holds the rest: the count of what is left, when there is one, and the sentence with the count's full length. The unsaved sentence is no longer in the description, so a reader that speaks both name and description does not hear it twice. The body still shows it. Over a count with nothing unsaved the dialog is named by its title as before (`Some of Your Data Is Still Missing`).
- **The failed sign-out's message**, in the Admin App and the Contestant App: it is named `Something went wrong` (C4 a, the existing `error.general`, translated in all seven catalogues), no longer `Log Out`, so its name differs from the header button that focus may return to. It holds one button for assistive technology, the text Close.
- **Every `Alert` with no actions of its own**, `Notification` among them, now exposes one Close. The round ✕ in its corner is still there and still closes the alert with a pointer. It is `aria-hidden` and out of the tab order. An `Alert` with actions, such as the data-consent, feedback and survey popups, keeps its ✕ as it was. Nothing changes visually.

None of this was heard. No run establishes what VoiceOver, NVDA or TalkBack say. For the UAT list:

- VoiceOver over a count.
