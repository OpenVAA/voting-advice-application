- **After every plan:** the gate-driver rows the plan's files touch; schema plans run pgtap + sql-lint + types-clean + equivalence
- **Before `/gsd-verify-work`:** the full gate driver and one complete, non-void, green `e2e-run.sh` run on one tree (D-04)
