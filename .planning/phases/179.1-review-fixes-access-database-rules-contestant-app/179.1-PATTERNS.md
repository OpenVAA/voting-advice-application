## Shared Patterns

### Schema change unit
Applies to plans 02–07: schema edit + appended migration + manifest line in one commit; `yarn db:types`; `yarn db:lint:sql`;
update the `07-rpc-security` census the change touches; pgTAP after `yarn db:reset`.

### Definer function hygiene
`SECURITY DEFINER`, `SET search_path = ''`, fully-qualified names, dashed header banner; policy helpers live in `private`
(not PostgREST-exposed), service-role RPCs revoke from PUBLIC/anon/authenticated.

### Server-side Supabase access
Every authenticated call on `locals.supabase` (the hook's client sets cookies); redirects via `buildRoute({ route, locale: locals.currentLocale })`; caller-supplied `next` through `safeRedirectTarget`.

### Svelte 5 context rule
New/changed components (confirm page, error view, settings page, Radio) read `ctx.X` for reactive accessors; destructure only stable refs (`t`, `getRoute`, `setPassword`).

### Comment hygiene
No `D-NN`, plan numbers, `.planning/` paths or narrative in `apps/`, `packages/`, `tests/` — only `see phase N`
(`assert:comment-hygiene`, `hygiene-grep-report.sh --assert-clean`).
