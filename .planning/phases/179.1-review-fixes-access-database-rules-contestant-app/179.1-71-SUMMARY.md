# Phase 179.1 Plan 71: A Log out withdraws every logout count, and every removal reaches the host's own domain Summary

**A Log out in either app now removes every logout count the browser holds before it signs out, whoever wrote it, so a count left by a closed tab can no longer end a session signed in afterwards. Every removal of the two cookies, on the page and in the server's hook, now also names the host's own domain, so a copy planted for an apex host is removed.**

## For the operator's reading

- **What a user now meets:**
  - **The count of a closed tab no longer ends a later sign-in.** Before this plan, the sequence was: the logout modal opens in one tab, that tab is closed, the user presses Log out in another tab and signs in again. About 40 seconds after the modal opened, the new session was ended with no message and its drafts discarded. Now the Log out removes the orphaned count, and the new session stays. This holds for the Log out of the Contestant App and of the Admin App, which both go through the shared auth context.
  - **A planted cookie for the host's own domain is removed.** On an apex deployment such as `example.org`, any subdomain could plant a `logout-pending` or `logout-deadline` with `Domain=example.org`, and nothing removed it. The browser was then signed out at every other navigation, with its drafts discarded. Now the page and the server both expire that copy.
- **The server's settled marker is left alone.** A Log out made right after the server ended a session still lets the page discard that session's drafts.
- **What stays unproven:**
  - The apex host in a browser. Every E2E origin is `localhost` or `127.0.0.1`, so no run plants a cookie for the host's own domain. The removal is unit-tested on the page's function and in the hook.
  - The Admin App's Log out withdrawing a count. It is unit-tested through the auth context it calls, but no browser run drives it.
  - A sign-out made with no Log out: the deadline's own sign-out in another tab, `signOutToLogin`, the sign-in actions and the identity provider's callback. Plans 72 and 73 build the server's half of G-1.
