which of the two they mean.

## Sampling Rate

- **After every task commit:** the narrowest `yarn workspace @openvaa/frontend vitest run <path>` that covers
  the task, plus `yarn workspace @openvaa/frontend lint` when the task touched `eslint.config.mjs` or the
  adapter directories.
- **After every plan wave:** `yarn test:unit && yarn lint:check` (this runs `svelte-check` via
  `turbo run typecheck` and all eight assert-scripts).
- **Before `/gsd-verify-work`:** the full phase gate above, including a green `yarn test:e2e`.
- **Max feedback latency:** ~15 s at task level, ~5 min at wave level.
