## Decisions Made

1. **The fixture split follows the measurement, not the plan's arithmetic.** See "Deviations" below.
2. **C7 ships in `CLEAN` flagged `silent: false`.** Research measured `return malformed(parsed)` tripping G5 — G5's one false positive — and named the mitigation: the outcome constructors take the issues as an argument, so `parseMalformed(issues, value)` carries the identifier and stays silent. The fixture is transcribed with both its mitigated and unmitigated bodies, and its case asserts only the mitigated one. That turns a research footnote into a standing constraint on `157.1-03`.
3. **One live case in the guard self-test.** Without it the file executes nothing at all — the `beforeAll` warm-up never runs and correctness invariant 2 (that the flag really loads this repository's own flat config) is unobservable, so a construction that silently resolved no config would make all 87 todo cases pass vacuously the moment `157.1-07` flipped them live. The case asserts `calculateConfigForFile` returns a rule set containing `no-restricted-syntax`, which is a measurement of the apparatus, not of the guard.
4. **Runtime module specifiers instead of literal imports.** `const LOG_LEVEL_MODULE = './logLevel'; await import(LOG_LEVEL_MODULE)` keeps TypeScript from resolving a module that does not exist yet, so both Task-2 files typecheck (`svelte-check`: 0 errors, 0 warnings) without a `@ts-expect-error` that would itself go stale.
