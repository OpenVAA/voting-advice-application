end-to-end production slice ahead of everything else. This phase overrides that, deliberately. The
milestone's standing acceptance rule (`REQUIREMENTS.md:7-13`) — *prove the guard fails before claiming
it guards* — was turned by Phase 143 (its SC-2) into a property of the **commit graph**: every OLD half

behaviour. A tracer slice would change behaviour first and make every subsequent blind half
unmeasurable. So plan 01 is measurement-only and writes **zero product bytes**. The ordering is
deliberate, not accidental.

Purpose: a guard that has only ever been observed working is indistinguishable from a guard that
cannot fail. This plan produces the "cannot fail" record for all fourteen controls this phase owes,
before any of them exists.
