1. **Two forms of the same command, and where each belongs.** Every **evidence** run in this phase —
   every ledger row, every two-run half, and the phase-close gate set — uses `TURBO_FORCE=true`,
   because `turbo.json` gives `typecheck` no cache disable and a replayed verdict is a claim about a
   **previous** tree. This control's two halves differ by one line in one file, so an unforced second
   run can replay the first's verdict and manufacture a false green. The **gate as shipped** to
   `package.json` and `main.yaml` does **not** force: caching there is a feature and CI cold-starts
   anyway. Write both facts into the ledger beside the row, not only into this plan.

   rather than passing it to turbo, and it silently does nothing. The substitute is

   measured string is a cache-bypass forced-execution verdict followed by the task hash, plus an
   aggregate cache summary line. A row that cannot show a forced execution is not a measurement.
