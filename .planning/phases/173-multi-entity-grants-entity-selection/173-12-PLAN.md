## Rulings and deviations carried by this plan

1. **Ruling O-Q5 shapes the spec.** A draft is carried across a switch through a reload, not through a
   click from the editor: the editor's existing prompt discards the draft on a confirmed navigation. The
   spec also asserts that prompt, with Cancel, as the one thing a switch from an editor raises.
2. **The zero-entity state is reached by deleting a grant after sign-in** (D-21's discretion): the login
   form refuses a token with no contestant-shaped grant, so the session cannot be grantless from the start.
3. **The shared session helper moves to a plain module** if Phase 172 left it inside a setup file: one
   Playwright test file cannot import another.
4. **`scripts/assert-a11y-scan-wiring.mjs` is not extended.** The new projects are held by the suite and by
   this plan's check that they are in the run.
