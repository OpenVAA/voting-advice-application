1. **A route group that lives for one plan.** `(protected)/(entity)/` holds the entity-level layout and the
   six pages; a group adds no URL segment. 173-08 renames it to the two route params. The cost is that the
   five route constants, the generated route map and the comments that cite a moved path change here and
   again there; the gain is that the load split is proven on unchanged URLs.
2. **More files than the phase's aim of about fifteen:** nine are pure moves and four are new test
   files. The first commit of Task 1 is the move alone, at full similarity.
3. **Neither load holds a branch for a missing entity object**; it left with 173-03. Its error code, map
   entry, messages and docs mention stay until 173-10 retires them with the screen (D-11).
4. **The header's logout on Help and Privacy signs out directly from this plan on**, where it opened the
   unanswered-questions dialog while the store still held the last entity. The store is emptied when the
   user leaves the entity tree; the dialog still opens on entity pages.
5. **The load split is two tasks, each leaving a tree that typechecks.** Task 2 arranges the user-level
   stages and the sign-out helper while the entity step still runs in the same file, so no layout or page
   changes; Task 3 moves the entity step one level down and splits the layout.
6. **This plan's full run is also the boundary proof of 173-06**, which closed on its gates alone. It is
   judged per project against the baseline, and Task 5 says which failures point back to that plan.
7. **The interim outcome for zero or several entities, and for an entity read that finds no row, is not
   pinned by any new test.** 173-08 and 173-10 replace both.
