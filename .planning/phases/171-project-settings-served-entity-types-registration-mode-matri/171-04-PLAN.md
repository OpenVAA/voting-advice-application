Binding on every task of this plan.

1. **Names are hints; the tree is the truth.** This plan was written before Phase 170 executed and runs after it. Paths, symbols, route keys, test ids and project names are in their post-170 form with today's name in parentheses at first use; `171-NAME-MAP.md` holds the resolved names.
