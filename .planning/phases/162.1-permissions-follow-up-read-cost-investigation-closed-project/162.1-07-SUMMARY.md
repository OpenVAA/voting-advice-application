## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Closed branch returned a partial `access` object that closed the candidate app**
- **Found during:** Task 1, first green run.
- **Issue:** The plan specified `{ access: { voterApp: false } }`. The app context merges DB settings with `mergeAppSettings` (`apps/frontend/src/lib/utils/settings.ts`), which is a shallow root-key merge. `access` was replaced whole, `candidateApp` became `undefined`, and `candidate/+layout.svelte` rendered the candidate MaintenancePage.
- **Fix:** Return `{ access: { ...dynamicSettings.access, voterApp: false } }`, with a comment giving the reason. A unit case asserts `candidateApp` stays `true`.
- **Files modified:** `supabaseDataProvider.ts`, `supabaseDataProvider.test.ts`
- **Commit:** `56ca7a4ff`, and the Task 2 cases in `ee6d9b4ac`

**2. [Rule 3 - Blocking] Concurrency test mock lacked `maybeSingle`**
- **Found during:** Task 1 unit run.
- **Issue:** `supabaseAdapter.concurrency.test.ts`'s tagged fake client only had `.single()`.
- **Fix:** Added a `maybeSingle` sibling and updated its docblock.
- **Commit:** `56ca7a4ff`

**3. [Rule 2 - Correctness] `_probes` excluded from the derived leaf list, with a written reason and a stale-exclusion throw**
- **Found during:** Task 1 config.
- **Issue:** `_probes` is a leaf. A `--project perm-closed-project` run applies no `@probe` grep, so depending on it would pull unseeded probes into the run, where they would fail.
- **Fix:** Added `CLOSED_PROJECT_EXCLUDED_LEAVES`. A config-load throw fires if an exclusion stops being a leaf.
- **Commit:** `56ca7a4ff`

**4. [Rule 3 - Blocking] Red for the second test needed a targeted run**
- **Issue:** In serial mode the login test was "did not run" in the plan's red run.
- **Fix:** A targeted run with setup and spec in one invocation, needed because global setup's `ensureProject()` reopens the project on every invocation. The first attempt used two invocations, ran against a reopened project and passed. It is recorded as void.
- **Evidence:** `e2e-red-before.txt`

**Total deviations:** 4 auto-fixed (1 bug, 1 correctness, 2 blocking).
**Impact on plan:** Deviation 1 was required for the D-16 candidate login to work at all. There was no scope creep.
