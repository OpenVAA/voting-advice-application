bucket whitelist plus own-folder confinement and a still-referenced check (D-20), EXECUTE revoked from API

service-role URL, so the fix must not open request forgery or a public delete RPC.

helper, `31-storage-cleanup.test.sql`, the API-only `storage-cleanup` Playwright project and spec.
