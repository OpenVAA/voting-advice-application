## Sampling Rate

- **After every task commit:** the workspace-scoped `test:unit`, plus `test:db` for schema tasks.
- **After every plan wave:** `yarn typecheck && yarn lint:check && yarn format:check && yarn test:unit && yarn workspace @openvaa/supabase test:db && yarn db:lint:sql`.
- **Before `/gsd-verify-work`:** the above plus the full E2E through `tests/scripts/e2e-run.sh` (no `--no-db-reset` after schema changes): 0 failed, 0 did-not-run, 0 flaky.
- **Max feedback latency:** 120 seconds (per-task quick commands).
- **Exit statuses are read directly, never through a pipe.**
