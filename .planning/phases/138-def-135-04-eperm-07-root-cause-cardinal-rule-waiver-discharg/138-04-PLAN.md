<objective>
Route the fix decision to the operator where CONTEXT.md requires it, apply the authorised fix, and
record the negative-control pair that criterion 2 demands.

RESEARCH's leading mechanism is a navigation-settle race whose remedy may be partly or wholly
test-side. CONTEXT.md D-05 pre-authorises only an APP-side fix; D-06 forbids the executor from
applying a test-side remedy unilaterally and requires it to stop and escalate with the evidence in
hand. This plan therefore leads with that checkpoint rather than treating it as an unlikely edge —
research judged it the likely path.

Purpose: criterion 2 is not "the fix works". It is "with the forcing harness applied, the pre-fix
code FAILS and the post-fix code PASSES". A fix accepted on "it stopped happening" does not satisfy
it, and the two halves must share one adversary.

Output: an operator decision on the fix tier, the fix itself, and `138-NEGATIVE-CONTROL.md` in the
format Phase 137 established.
