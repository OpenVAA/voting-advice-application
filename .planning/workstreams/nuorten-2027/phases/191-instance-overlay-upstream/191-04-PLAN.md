<objective>
Lay `instance/messages/<locale>.json` over the frontend's message catalogues at compile time. When instance message files exist, `paraglide.options.ts` validates them and writes a generated inlang project at `apps/frontend/.instance/project.inlang/settings.json` whose `pathPattern` is the base list (rebased) with `instance/messages/{locale}.json` appended LAST (measured with Paraglide 2.25.4: last file wins, missing files ignored, patterns resolve against the parent of the `.inlang` folder). Without them, the project is `./project.inlang` exactly as today. Both consumers (`vite.config.ts` and `scripts/compile-paraglide.ts`) already import `PARAGLIDE_OPTIONS`, so neither file changes.

Purpose: SC-2 for translation overrides (one file per locale, per research Open Question 7); SC-3 (identity without an instance). Also correct `apps/frontend/messages/README.md` rule 2 (Open Question 6).
Output: extracted catalogue helpers, the instance-messages module + tests, instance-aware `paraglide.options.ts`, README fix.
</objective>
