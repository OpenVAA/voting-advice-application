| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-191-06 | Tampering (CSS injection) | applyThemeToAppCss | mitigate | values reach the transform only through Plan 01's schema (six-digit hex, charset-restricted font name); the transform replaces only the value span of known declarations and throws on drift, never appends rules |
| T-191-07 | Tampering (XSS) | AppLogo img src | mitigate | `AssetUrlSchema` (same-origin path or `https:` only, no `javascript:`); Svelte escapes attribute values |
| T-191-08 | Denial of service | app.css drift | accept | drift fails the build with the declaration named, which is the intended guard |
| T-191-09 | Accessibility regression (WCAG contrast) | instance colours | transfer | contrast of an instance palette is the instance's responsibility; the optional `*-content` keys let it fix text contrast; a11y-smoke runs below on the base palette |
</threat_model>
