- THE SITTING CONTRACT, which each script of this plan and of plans 09 and 10 meets:
  (1) one file, `#!/usr/bin/env bash`, nothing newer than bash 3.2, run as `bash PATH --attempt ID [--from N]` from any directory; a header that says what each step does, what `--from N` runs again and never runs again, and where the reply is saved;
  (2) every fact a step establishes is a reply line `s<step>_<field>=<value>`; the field's last word is never one of the reply screen's secret words (`secret`, `password`, `token`, `key`, `credential`, `bearer`, `authorization`, or a word ending in one), so shapes are reported as `…_shape=ok`, presence as `…_present=yes`; no value holds a key, a JWT, a run of 32 or more hexadecimal or base64 characters, an e-mail address, an IP address, the pooler host or an assumed-role session name;
  (3) after each step a gate compares the named lines with what the step must print, goes on by itself when all match, and otherwise shows each differing line and asks y or n from the terminal; n stops the sitting;
  (4) a step that writes is announced in red with what it changes and runs only after `y` is typed; before acting it reads the present state and, when its effect is already in place, records `…_already=yes` and does not act;
  (5) `--from N` always runs the steps that establish the session (tools, target, secrets, connection) and never runs a writing step below N;
  (6) a command that fails leaves its status in a named line and the first error line of its output, scrubbed, in another;
  (7) secrets are read with `read -rs` from the terminal, live only in the script's process, reach a command through its environment, standard input or a mode-600 file in a `umask 077` temporary directory, never through an argument, and are unset on exit; a key's shape is judged by its prefix alone;
  (8) on every exit, also an interrupt, the temporary directory is removed and the reply is assembled (`answer_attempt=ID` first, every line prefixed `answer_`, `answer_stopped_at=` when it stopped), printed, copied with `pbcopy` when present and saved under `tmp/189.1.2/`, which Git ignores;
