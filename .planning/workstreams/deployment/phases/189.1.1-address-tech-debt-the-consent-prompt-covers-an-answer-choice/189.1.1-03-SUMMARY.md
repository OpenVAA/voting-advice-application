## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The sitting's channel-binding probe took libpq's password-file warning as its line**
- **Found during:** Task 2 (the operator's note in the bound reply)
- **Issue:** With `PGPASSFILE=/dev/null`, libpq first prints `WARNING: password file "/dev/null" is not a plain file`, and `grep -m1 .` caught that instead of the error. The operator read the next line.
- **Fix:** The sitting's step 2 now creates an empty `0600` file in the sitting's log directory and names it as `PGPASSFILE`. An empty regular file draws no warning: Task 3's own legs use it and their first log line is the error. The evidence records the warning, the operator's reading and the change. The sitting was not run again.
- **Files modified:** evidence/189.1.1-03-root-ca.md
- **Commit:** b9d4042e5

- **Found during:** Task 3
- **Issue:** libpq's line quotes the leaf's wildcard name. That name holds the pooler's domain, which the plan's leak check forbids in the evidence.
