## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] The settings TLS-line mutation updated in Task 1, not Task 2**
- **Found during:** Task 1
- **Issue:** The existing case "sees the TLS requirement dropped from the settings check" matched `PGSSLMODE: require`. Once the workflow moved to `verify-full`, its `mutate()` would throw, and Task 1's `<verify>` requires a green suite.
- **Fix:** The pattern was changed to `PGSSLMODE: verify-full` in the Task 1 commit. The case stays red on its mutation.
- **Files modified:** infra/scripts/deploy-workflow.test.ts
- **Commit:** 6353189d7

**2. [Rule 2 - Missing critical] A seventh mutation case, and forbidden connection-string overrides**
- **Found during:** Task 2
- **Issue:** In the per-step missing-root mutations, `rootCaPathHolds` is already false because the two paths differ, so they do not show that the existence check works by itself (WR-03). Separately, a `sslmode=` or `sslrootcert=` in a connection string, or a `PGCHANNELBINDING` line, would get past both env pins: the first weakens verification, and the second refuses every connection on the current pooler.
- **Fix:** Added the case "both database steps pointed at one root that does not exist", which goes red on the existence check alone (shown by weakening the check). The verify-full-only case also asserts that `deploy.yml` contains no `sslmode=`, `sslrootcert=` or `PGCHANNELBINDING`.
- **Files modified:** infra/scripts/deploy-workflow.test.ts
- **Commit:** 6353189d7, a3448b13e

**3. [Rule 1 - Type safety] `mutateEnvLine` splices the text itself instead of calling `mutate()`**
- **Found during:** Task 2
- **Issue:** `mutate()` takes a string replacement. The replacement holds `${{ … }}`, and a string replacement would treat its `$` sequences as special patterns. Widening `mutate()` to take a replacer function would need an `any`-typed signature.
- **Fix:** `mutateEnvLine` matches with `envLineOf`, splices the text, and has its own guards that throw when the line is missing or unchanged.
- **Files modified:** infra/scripts/deploy-workflow.test.ts
- **Commit:** a3448b13e
