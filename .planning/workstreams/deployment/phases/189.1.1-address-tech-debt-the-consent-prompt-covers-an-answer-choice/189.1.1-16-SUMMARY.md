## Decisions Made

- **`E2E_SLOW_HOST=1` for the five targeted runs.** When they started, another project's test processes held the host at a load average of 33 on 14 cores. The flag is the posture tests/README.md provides for this (3 workers). It is recorded in `E2E_COMMAND=`.
- **`pressEscape` only considers connected dialogs.** It picks the topmost dialog among those still connected and open. A dialog left open by an earlier case and then unmounted is no longer in a browser's top layer, so it must not be treated as topmost.
- **`contestant-journey` stays in the targeted set as the plan names it.** The grep shows its two Escapes act on the CSS nav drawer of `Layout.svelte`. Only `contestant-entity-selection` presses Escape on the held sign-out modal.
