## Notes for the legal reviewer brief (section 6), not edited

The shipped modal matches "a modal dialog, every dismissal declines". Escape, the close button (named "Close dialog"), a backdrop click and a platform close each store `denied`. A stored decline keeps the prompt from opening again. Nuances the brief does not state:
- Escape pressed while the prompt's "more information" dialog is open closes only that inner dialog and records nothing. The next Escape declines.
- The prompt opens once the page has hydrated (the voter layout's `onMount`). It is not part of the server-rendered page, so the page can be used for a moment before the prompt appears.
- When a voter-app notification is configured, it is queued first, and the consent prompt opens only after it closes.
- "Does not appear again" is per browser storage. Clearing the site's localStorage brings the prompt back.
