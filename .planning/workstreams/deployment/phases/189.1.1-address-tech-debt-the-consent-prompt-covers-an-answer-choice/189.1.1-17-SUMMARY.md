## Decisions Made

- **The parties tab before opening the drawer.** In the analytics dataset a candidate card has no subcards, so its action link wraps the whole article and is not a descendant of `entity-card`. `openEntityDetailsForCard` looks for a descendant action, so it waits forever on a candidate card. A party card's action is its header. `voter-journey-mobile.spec.ts` selects the parties tab before the same call for the same reason. The fixture was not changed.
- **Red by mutation, not on the tree.** The tree outcome was already correct, so the plan's mutation branch applied: `e.stopPropagation();` was deleted in the working copy and restored with `git checkout --`.
- **No `E2E_SLOW_HOST`.** The load average was 3.9 to 8.1 on 14 cores, and each run observed 6 workers.
