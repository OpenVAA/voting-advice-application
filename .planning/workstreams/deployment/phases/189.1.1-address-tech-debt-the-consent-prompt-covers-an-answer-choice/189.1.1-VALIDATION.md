## Sampling Rate

- **After every task commit:** the touched unit file(s), red first where the task is TDD
- **After every plan:** one targeted E2E run per project the plan serves, after its last code commit (CLAUDE.md ruling 2026-11-09), with project deltas recorded against plan 01's baseline
- **Before `/gsd-verify-work`:** plan 15's gates and one green full E2E run, judged against 729 + pre-phase delta (+13 at planning) + the phase's deltas
- **Max feedback latency:** 600 s per foreground gate (longer gates run in the background)

Note: `node tests/scripts/e2e-spec-verdict.mjs` accepts no `--no-flaky` flag (exit 2); a flaky test always fails a verdict.
