### The fix

The delay set aside first with `git checkout -- tests/tests/specs/contestant/contestant-entity-selection.spec.ts` (`git status --porcelain -- apps packages tests` empty afterwards). In `createContestantEntityPages`, before the object it returns, a local `async function expectPath(pathname: string): Promise<void>` awaits `expect(page).toHaveURL(exactPathRe(pathname), { timeout: TIMEOUTS.slowPage })`; its TSDoc says that it asserts the page's path is exactly `pathname`, and that after a navigation inside the application the address changes only once the server has answered the request for the next page's data, so the wait has the budget of a server round trip. `expectOnHome`, `expectOnProfile`, `expectOnQuestion` and `expectOnQuestionsOverview` each call `await expectPath(...)` on the path expression they used before, and keep their visibility waits and their TSDoc. `tests/tests/helpers/timeouts.ts`, the spec, the other fixtures and `tests/playwright.config.ts` are not touched.
