- `type StartupEnv = Readonly<Record<string, string | undefined>>`
- `type StartupRule = (env: StartupEnv) => Array<string>` — returns the variable names the rule finds missing; an empty array when satisfied
- `const REQUIRED_ENV: ReadonlyArray<string>` — exactly `PUBLIC_SUPABASE_URL`, `PUBLIC_SUPABASE_ANON_KEY`, `PUBLIC_PROJECT_ID`, `ORIGIN`, in that order
- `const STARTUP_RULES: ReadonlyArray<StartupRule>` — holds one rule today, the one over `REQUIRED_ENV`
- `function missingRequiredEnv(env: StartupEnv, rules?: ReadonlyArray<StartupRule>): Array<string>` — names in rule order, each once; never throws

Error text thrown by `init`: `Required environment variables are not set: ` followed by the names joined with `, `.

Diagnostics: route `GET /api/diagnostics`; switch variable `DEPLOYMENT_DIAGNOSTICS`, on only when its trimmed, lower-cased value is `true`; body `{ origin: string, clientAddress: string | null, clientAddressError: string | null, headers: Record<string, string> }`; header `cache-control: no-store`.
