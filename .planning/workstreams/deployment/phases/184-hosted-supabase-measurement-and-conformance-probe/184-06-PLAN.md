<interfaces>
Provider `supabase/supabase` 1.11.0, read from its schema (RESEARCH Item 12): `supabase_edge_function_secrets` has `project_ref` (required), `secrets` (required, a set of `{ name = string, value = string (sensitive) }`), `secret_digests` (computed map) and `id`. A name must not start with `SUPABASE_`. On apply the provider deletes remote secrets that are in its state but missing from `secrets`, and leaves alone those it never managed. The value is stored in state in plain text.

Names the functions read (their sources): `PUBLIC_PROJECT_ID`, `SITE_URL`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, `SMTP_USER`, `SMTP_PASS`. `SMTP_FROM` is the sender address, which the SES SMTP user's policy restricts to `noreply@<domain>`; the module's `smtp.admin_email` holds that address.
</interfaces>
