## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a pushed branch → the gated job | Only the environment's reviewer and branch policy stand between a push and the deploy role |
| the gated job → AWS, the persistent Supabase project | Writes that a later commit cannot undo |
| the run log and the step summary → the public | The repository is public |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-187-21 | Elevation of privilege | an ungated apply | high | mitigate | One job holds every hosted write and names `environment: staging` (reviewer, branch policy, secrets released on approval); no `main` and no pull-request trigger; guarded |
| T-187-22 | Information disclosure | secrets in the smoke step or the log | high | mitigate | Supabase and database secrets only in the link, migrations and functions steps' `env`; the smoke step's `env` holds none (the gate refuses them anyway); the access token reaches `curl` on standard input; `show -no-color` only |
| T-187-23 | Information disclosure | the contestant's typed values in Playwright output | high | mitigate | No artifact upload anywhere; the output directory is under `$RUNNER_TEMP` and removed with `if: always()`; the deployed config writes no HTML report (186 review fix) |
| T-187-24 | Denial of service | a cancelled apply leaving the lock | medium | mitigate | `cancel-in-progress: false`, a 60-minute timeout above the longest observed apply, credentials assumed again before the apply; `terraform force-unlock` documented by plan 187-06 |
| T-187-25 | Repudiation | a failed run nobody hears of | medium | mitigate | `if: failure() || cancelled()` alert through the confirmed subscription, naming the stage and the run |
| T-187-26 | Tampering | a build that is not the commit | medium | mitigate | The build script's refusals and the archive context; the smoke gate's `PASS sha`; the served-build re-read after the specs |
| T-187-SC | Tampering | npm installs | high | mitigate | `yarn install` from the committed lockfile by setup-yarn; Playwright's Chromium from its own installer; no new package |
</threat_model>
