The operator applies the zone and mail root and re-runs the account asserts now that the SMTP user exists. The executor reconciles the DKIM signing zone and prepares the delegation record.

Output: a dated evidence file, a corrected variable file if needed, and the delegation record with the name servers.

Decisions implemented: D-02 (the long-lived mail root applied), D-06 (the identity and its records), D-08 (the account-side check repeated), A-02 (the DKIM zone compared with `SigningHostedZone`).
