The helper is a bash script in strict mode with a header that states its commands, its exit codes and the rule it serves. It lives in the planning directory because it serves the plans, not the product. Its commands are those of the behaviour list. Details:
    - The attempt directory is `tmp/183-evidence/` under the repository root. `new` proves it ignored with `git check-ignore -q tmp/183-evidence/x`; if that fails it uses `${TMPDIR:-/tmp}/183-evidence/` instead and says so.

Its screen is specified by the form of a line and the shape of a token as well as by name, so that it does not depend on how a paste happens to be formatted. It applies five rules in this order and reports the first hit by line number and class.
    - Rule 1, line form (class `unnamed-line`). Every non-empty line is one of four forms: a record line (`OPERATOR_…=` or `PLAN_REVIEWED=` at the start of the line); a named result line (`s`, a step number, an optional lower-case letter, `_`, a field name of lower-case letters, digits, `_` and `.`, then `=`); an answer line (`answer_<name>=`); or a note (`note: `). Raw command output, JSON, and a value on a line of its own are none of these and are refused whatever they hold.
    - Rule 2, secret names (class `secret-name`). Anywhere in a line, a name followed by a value is refused when the name's last word is a secret word. A name is the run of letters, digits, `_`, `-` and `.` that stands before the delimiter. The delimiter is `=` or `:`, with optional spaces and an optional closing quote before it and an optional opening quote after it; that covers shell, YAML, HCL and JSON. The name is split into words at `_`, `-`, `.` and at each change from a lower-case letter or a digit to a capital; trailing words made of digits are dropped; case is ignored. The secret words are `secret`, `secrets`, `password`, `passwords`, `passwd`, `passphrase`, `passphrases`, `pass`, `pwd`, `token`, `tokens`, `key`, `keys`, `credential`, `credentials`, `bearer` and `authorization`, and a last word that ends in one of them (`apikey`, `authtoken`) counts as one. That also refuses a harmless name whose last word merely ends in one, such as `bypass` or `monkey`; this is intended, the header says so, and the operator rewords the line. The values `(sensitive value)` and `null`, and an empty value, are not a value. `(known after apply)` is a value: no checkpoint asks for a plan line that could carry it.
