## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet mail receivers → the staging domain | Receivers decide from DNS whether a mail claiming the domain is genuine |
| holder of the SMTP key → SES | The key is a long-lived credential handed to the hosted auth service and to Edge Functions |
| Terraform state → readers of the state bucket | The access key's secret and the derived SMTP password are written to this root's state in clear text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-183-15 | Spoofing | DNS records in `mail-ses/main.tf` | medium | mitigate | Task 2: three DKIM CNAMEs with 2048-bit keys, SPF on the MAIL FROM domain, DMARC `p=quarantine`, and `REJECT_MESSAGE` so a broken MAIL FROM is not masked |
| T-183-16 | Spoofing | `aws_iam_policy.ses_send` | medium | mitigate | Task 2: the only permission is `ses:SendRawEmail` on the identity's ARN with `StringEquals` on `ses:FromAddress`, so the key cannot send as another identity or address |
