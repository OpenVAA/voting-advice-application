The SIGTERM and SIGINT listeners only record: adapter-node's own listeners drive the shutdown. TSDoc on every export, stating that the count is approximate for a streamed body, which can outlive `resolve`.

    In `hooks.server.ts`: create one counter at module level; add `inFlightHandle` as the first handle of `sequence`, which calls `enter()` before `resolve` and `leave()` in a `finally`; in `init`, after the start-up check returns without throwing, call `registerShutdownLog(inFlight)`. The `dev || building` guard stays first.
