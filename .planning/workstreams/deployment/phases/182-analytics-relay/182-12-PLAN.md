    - `privacy.analytics.content.gated`: usage data is collected only after the visitor agrees. It covers the answers given, the time spent and the results viewed. The events of one visit are joined by an identifier that is held in the page's memory only and is gone when the page is reloaded or closed. The data is sent through this site's own server, which passes on neither the visitor's network address nor the browser's identification. Nothing about this is stored on the device except the visitor's choice. A choice made on this browser applies to every part of the application opened in it, and it can be changed on the privacy page.
    - `privacy.analytics.content.free`: this deployment collects usage data without asking. Every event that tells an answer or a preference is sent on its own, with no identifier shared with any other event, so answers cannot be joined to each other or to page views. The same statement about the site's own server, the address and the browser identification, and that nothing is stored on the device.
    - `privacy.analytics.pageviews`: whatever the visitor chooses, the application counts page views: which kind of page was opened, in which language and for how long. The count has no identifier.
    - `privacy.analytics.gpc`: when the browser sends the Global Privacy Control signal, nothing is collected, the page-view count included, and the visitor is not asked. Nothing is stored to remember the signal.
    - `privacy.dataCollection.info`: one or two sentences for the consent control: usage data goes through this site's own server to the analytics service the publisher uses; no cookies are used for it.
    - `privacy.usageData.title` and `privacy.usageData.content`: the paragraph for the terms of use. Use of the application is measured in the same way in the voter application, the Contestant application and the Admin application. Name the three applications with the names the catalogues already use for them.
