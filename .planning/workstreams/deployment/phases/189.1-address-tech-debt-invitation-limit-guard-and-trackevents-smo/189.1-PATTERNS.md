## Pattern Assignments

### `infra/scripts/check-deployment-settings.sql` (NEW)

**Analog:** `infra/scripts/check-seed.sql`

Header convention (copy structure: purpose line, what it reads, "reads and never writes", run line, `\i` caveat, exit-status table):
```sql
-- Seed check: does this database hold anything of the local seed?
-- ...
-- It reads and never writes, and it never prints a key. ...
-- Run, with the connection in the libpq variables PGHOST, PGPORT, PGUSER, PGDATABASE and PGPASSWORD, as a role that reads auth.users and public.storage_config:
--   psql -X -f infra/scripts/check-seed.sql
--
-- Run it by itself. Included from another script with `\i`, a finding ends this script only, and the status is the including script's.
--
-- Exit status, which is psql's own and is the verdict:
--   0  nothing of the seed was found
--   2  the connection was refused or lost
--   3  a finding, reported in an error whose message begins `check-seed:`. Any other error with this status means the check could not run.
\set ON_ERROR_STOP on

DO $check$
DECLARE
  ...
BEGIN
```
Body: use RESEARCH.md Pattern 1 skeleton (`SELECT count(*), bool_and(behind_cloudflare) ... FROM private.deployment_settings`; two `RAISE EXCEPTION 'check-deployment-settings: ...'` branches). Connect as `postgres` (owner), never an API role. No historical narrative in comments.

### `tests/tests/utils/callerLimitProbe.ts` (NEW, pure)

**Analog:** `tests/tests/utils/deployedTarget.ts` — pure exported functions with TSDoc, inputs injected (e.g. `env: GateEnv`), named-message failures:
```ts
 * @throws `SMOKE INPUT MISSING: <names> (read from the environment only, never printed)`, naming every unset or blank variable and holding no value.
 */
export function requireSmokeInputs(names: ReadonlyArray<string>, env: GateEnv): Record<string, string> {
  const missing = names.filter((name) => (env[name] ?? '').trim() === '');
  if (missing.length > 0) {
    throw new Error(`SMOKE INPUT MISSING: ${missing.join(', ')} (read from the environment only, never printed)`);
  }
  return Object.fromEntries(names.map((name) => [name, env[name] ?? '']));
}
```
Shape: RESEARCH.md § Code Examples (`ProbeAnswer`, `ProbeResult` discriminated union, `probeCallerLimit(post, freshCode, limit, windowSeconds)`). Export the constants (`CALLER_LIMIT = 30`, `CALLER_WINDOW_SECONDS = 600`) so the test pins them. No imports of `accountAccessClient`, supabase-js, dotenv, dev-seed (ESLint deployed block). Strict types, no `any`.
