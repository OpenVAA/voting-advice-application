## Decisions Made

- A 200 answer counts as a code status only when it is an object with exactly the key `status` and the value is `valid`, `used` or `unknown`. A 429 answer counts as the function's refusal only when it is an object with exactly the key `error` equal to `too-many-requests`. A body that is not JSON fails both tests.
- The final reason names the limit + 1 actually used, so a probe run with another limit reports that number (a unit case runs it with limit 3: `no 429 within 4 calls`).
