## Accomplishments

- `caller-limit.smoke.ts` reads `/` through the `request` fixture, which resolves against the gated base URL, and hard-asserts `ok()`. It builds the target with `checkCodeTargetFrom(extractServedEnv(html), extractServedProjectId(html))` and sends every call as `request.post(call.url, { headers: call.headers, data: call.data })` from `checkCodeRequest`, adding no header. It then runs `probeCallerLimit(post, freshCheckCode)` and asserts `ok: true`, using the probe's reason as the failure message. It prints `caller_limit_admitted=<n>` and `caller_limit_retry_after=<s>` and nothing else. `test.use({ trace: 'off' })` is set because the call headers carry the anon key. The file header states the throttle row it writes and the 10-minute refusal of the caller's address that a run leaves behind.
- The deployed lint block's `files` now includes `tests/utils/callerLimitProbe.ts`, and `eslint --print-config` on the util shows the block's restrictions.
- `voter.smoke.ts` installs `page.addLocatorHandler` before `navigateToFirstQuestion(page)`. The handler targets the button `/don.t want to share my data/i` inside the dialog `/collecting usage data/i` and clicks it. The spec does not grant consent, pre-seed storage or set Global Privacy Control. The header says when the prompt is shown, why the handler is local to this spec, and that a voter notification queued ahead of the prompt would need its own handler.
