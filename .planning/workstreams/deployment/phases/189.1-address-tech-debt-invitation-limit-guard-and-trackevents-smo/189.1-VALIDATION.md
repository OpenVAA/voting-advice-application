## Sampling Rate

- **After every task commit:** the targeted vitest file(s) of the task, plus `yarn lint:check` on touched workspaces
- **After every plan wave:** `yarn test:unit:infra && yarn test:unit:tests && yarn lint:workflows`
- **Before `/gsd-verify-work`:** `yarn test:unit`, lint, format, one complete green full E2E run, the operator-approved deploy run green with the smoke tests, and the trackEvents-on voter smoke green
- **Max feedback latency:** 120 seconds (unit level)
