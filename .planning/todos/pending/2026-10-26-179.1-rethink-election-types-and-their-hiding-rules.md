## Problem

Under the shipped default `entities.hideIfMissingAnswers.candidate: true`, the voter app drops every organization nomination whose `candidateNominationIds` is empty: the organization branch of the voter filter reads the candidate key and keeps only organizations with a visible candidate. That includes organizations that never had a candidate, not only those whose candidates were all filtered out, so an organization with no candidate nomination is hidden from voters whatever it answered itself (175 WR-01).

The organization is not told. Its own hidden-check, `isHiddenIfMissingAnswers`, reads only the organization key, which defaults to `false`, so the Contestant App's home, profile page and logout modal never say that it is hidden. Since organizations can fill in their own answers, a party-only setup under the default shows voters no party at all.

## The operator's note

Today's behaviour is right for open-list elections with forced candidate choice, the Finnish model: there a voter votes for a candidate, a party is shown through its candidates, and a party with no candidate cannot be voted for. It was kept as it is for that reason.

## The question

How should election types drive these and the other hiding rules? The behaviour above follows from one election model, while the settings are written as if the rules were independent of it. To decide:

- Which election types the framework recognises (open list with forced candidate choice, closed list, party-only, mixed, and so on), and where a project or an election states its type.
- For each type, which entities a voter sees and when one is hidden: an organization with no candidate, an organization whose candidates were all hidden, a candidate with missing answers, and the existing `hideIfMissingAnswers` keys.
- Whether the hiding rules become defaults derived from the election type, with the settings as overrides, or stay independent settings with the type only choosing their defaults.
- That an entity hidden by any rule is told so in the Contestant App, by a check that reads the same rule as the voter filter.
- Unit cases for each type under its defaults, including an organization with no candidate.
