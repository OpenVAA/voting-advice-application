## Resolution

root_cause: |
  G-7D (CONFIRMED): the multi-selector variant keys in the message source are space-separated ("infoQuestionsLeftPlural=one opinionQuestionsLeftPlural=one"), a syntax @inlang/plugin-message-format never supported (it splits selectors on ","). Plugin 4.6.0 (what jsdelivr serves for the settings' @4 URL, loaded network-first by @inlang/sdk 3.0.6 under @inlang/paraglide-js 2.25.4) parses the key as one selector with the value "one opinionQuestionsLeftPlural", so no variant can match and the compiled function returns its own key. Hand-authored in 6b3be8ea5 (phase 17-01 ICU conversion). Same pattern, exactly: contestantApp.logoutModal.itemsLeft and components.video.timeLeft (unused), each in all 7 locales (14 messages, 91 variant keys); no other multi-selector message exists. Comma separator CONFIRMED to compile to `a === "one" && b === "one"` (70/70 -> 1/70 key returns; the 1 is fr "many").
  G-7 (mechanism measured; speech UNCONFIRMED): the unsaved warning is carried only by the dialog's aria-describedby, while its accessible name is "Log Out" (title = countedTaskLeft && !unsavedOnPage ? logoutModal.title : common.logout). Focus enters the dialog by a programmatic focus on Continue 225 ms after showModal() dropped focus to body (showModal runs while the dialog is display:none under the `hidden` class); VoiceOver announces the dialog it entered as name + role + item count ("Log out, Panel, 9 items" = the AX node's name and its 9 unignored children) and then the button, and does not speak the description. The count modal sounded fine because its NAME ("Some of Your Data Is Still Missing") carries the warning. The suspected timing cause is eliminated by measurement.
  G-7B: "Close Close" (CONFIRMED in the AX tree): the Alert renders two buttons both named t('common.close') - the text Button of its no-`actions` branch and the X with an sr-only "Close". "Log Out Log Out" (UNCONFIRMED): the header Log out button, named "Log Out", receives focus from dialog.close() in the same frame the role=alert named "Log Out" appears; the alert's subtree holds no other "Log Out".
candidate_causes_considered:
  - code: modalOpen/unsavedOnPage timing (eliminated); name/description split (G-7); duplicate button names (G-7B); focus restore on close (G-7B)
  - config/data: plugin version resolved from CDN (eliminated as cause, it only changes the wrong string); message source syntax (G-7D cause)
  - environment: VoiceOver's AXCustomContent treatment of aria-describedby on macOS 14+ (G-7, contributing, UNCONFIRMED)
