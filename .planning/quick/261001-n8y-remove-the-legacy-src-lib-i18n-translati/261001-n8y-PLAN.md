- the `TranslationKey` generator;

- `translations.test.ts`'s cross-catalog drift guard;
- `editTranslations.ts`, which the orchestrator's list missed and which reads the legacy directory as its data source;
- `tests/tests/utils/rawKeyScan.ts`, also missed by that list, which reads the legacy `en` directory at E2E runtime and would crash every a11y scan if the directory vanished first;
- stale mentions in comments and docs.

The planner measured both catalogs: they currently agree on all 595 base-locale keys, and so does the committed union. Repointing the generator should therefore change only the header line of `translationKey.ts`. Any other change is a finding to explain, not a diff to accept.
