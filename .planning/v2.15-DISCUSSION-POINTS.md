### O6 — Phase 152's D-A4 scan: manual review, with a measured heuristic partition

**Direction:** *"we'll need to check all sites manually but if it looks unwieldy, some heuristics can be
devised for separating allowed paragraph breaks from manual line-wrapping."*

It is unwieldy, so the heuristic was built and measured rather than proposed. Full evidence in
`.planning/phases/152-comment-naming-hygiene-sweep/152-WRAP-HEURISTIC.md`; prototype alongside it.

**The finding that reframes D-A4.** `printWidth` is **120** (from `.editorconfig`), but the comment corpus
is not wrapped to 120 — median per-file maximum comment column is **83**, the histogram peaks at **78**,
and only 4.9% of files reach the 111–120 band. Testing "would the next word have fitted?" against 120
therefore flags **14,565** breaks: essentially every wrap in the repo. That is the yardstick being wrong,
not a finding about forced line breaks.

**The heuristic** compares each break against **its own file's prevailing wrap width** — the densest
5-column band among that file's upper-half comment lines, computed over lines ≤ 120 so an ASCII table
cannot set the width. Seven rules, each individually justified: `.prettierignore`d files, oversize lines,
structural next lines, JSDoc tag lines, breaks the file's own width explains, sentence boundaries, and
near-margin fills.

**Result: 16,660 breaks examined · 95.4% auto-classified · 762 left across 251 files** — an **18.5×**
reduction against the planner's literal 14,094, and a reviewable number. The residue concentrates
(`argument-condensation` holds ~90 across four files), so review proceeds file-by-file.

**Decision: run D-A4's detection verbatim and codify the seven exclusions as committed, individually
warranted rules.** Nothing is silently out of scope — every exclusion carries its measurement and can be
challenged singly — and the human still reads all 762. The heuristic removes only the 15,898 breaks that
provably need no eyes.

**Deliberate soft edges, recorded so they are not mistaken for rigour:** a sentence-ending line can still
be hand-wrapped, and rule 6's 15-column slack is a free parameter. Both are tuned to favour false
negatives, because a missed hand-wrap costs nothing while a false positive sends a reviewer to a clean
site. The slack deserves a sensitivity check when `152-02` productionises the prototype.

This is the evidence `152-14`'s blocking `checkpoint:decision` should carry — the checkpoint stands,
better armed.
