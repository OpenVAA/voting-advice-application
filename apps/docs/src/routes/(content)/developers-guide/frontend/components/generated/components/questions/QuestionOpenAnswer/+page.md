# QuestionOpenAnswer

Display an `Entity`’s open answer to a question. If the content is empty, nothing will be rendered.

### Properties

- `content`: The open answer text.
- Any valid attributes of a `<div>` element

### Usage

```tsx
<QuestionOpenAnswer content={openAnswer} />
```
