# Candidate Components

> See also the online doc [Components](https://openvaa.org/developers-guide/frontend/components) (or [locally](</apps/docs/src/routes/(content)/developers-guide/frontend/components/+page.md>))

This directory contains components specific to the contestant application used throughout the OpenVAA frontend.

| Component                           | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ContactSupport`                    | A block that leads the user to support: an optional lead-in and one button. Its `action` is `'help'`, a link to the support section of the Help page, or `'email'`; `variant` and `iconPos`, the position of the button's icon, are passed to the button.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `EmailEntry`                        | An email address and its confirmation: two `EmailField`s compared trimmed and without regard to case. `validate()` shows at each field what is wrong with it, moves focus to the first field in error and returns the verdict. It serves any screen that asks a user to enter and confirm an address.                                                                                                                                                                                                                                                                                                                                                                                                             |
| `EmailField`                        | One labelled email input with an optional hint and an error: the input library's `Input` of the `email` kind. Its label, `name` and `autocomplete` token are given by its caller, which also says when the field is in error; `checkValidity()` answers for the control, and an empty field is not usable.                                                                                                                                                                                                                                                                                                                                                                                                        |
| `EmailSentPanel`, `EmailSentResend` | The body of the "email sent" screen and its one action. The body is fixed sentences chosen by its `wording`, the address the user typed in bold in the first of them, a support sentence whose words are the link, the action it is given and a polite status region; it shows nothing the server answered. The action is a "Send again" button whose label ends with the seconds left; it is unavailable, and still a tab stop, while seconds are left or a request is in flight; it also serves the "Send again" of an address awaiting its confirmation link, under test ids its caller gives. The class `ResendCountdown`, exported beside them, computes the seconds from the time the last request settled. |
| `LogoutButton`                      | Logs the user out. It first asks the entity's tasks whether anything is left that the user can do now, and offers to stay only while the profile or the questions task has unanswered questions to count.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `NotEditableNote`                   | A note saying that something cannot be edited, with one Contact support button. Its `reason` is `'answersLocked'`, `'nominationsLocked'` or `'nominationsAnswersLocked'`, and a second sentence is passed as children. It goes in `MainContent`'s `note` snippet.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `NothingToEdit`                     | The view of a signed-in user who edits no entity.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `PasswordField`                     | A password input with a button that shows or hides the password. Its `name` is `password` unless one is given. With `externalLabel` it renders no label and no placeholder, for a caller that renders a visible label; `describedby` and `invalid` tie an error to the input.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `PasswordSetter`                    | The form for choosing a password: the rule list, a password field and its confirmation, each with a visible label. With `username` the form holds the account’s address in a read-only field that is not rendered, for a password manager, and the rule list refuses a password that contains it. `validate()` judges the password as typed, shows what is wrong at the field it concerns, moves focus there and returns the verdict.                                                                                                                                                                                                                                                                             |
| `PasswordSignIn`                    | The password half of a sign-in form: the labelled password field, the message of a refused sign-in, the link to the forgot-password page and, where it is offered, the link for a user who has not set a password. Both links carry the typed address. Each screen that renders it passes its own test ids.                                                                                                                                                                                                                                                                                                                                                                                                       |
| `PasswordValidator`                 | Shows which password rules a typed password meets.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `ReadFailure`                       | The view shown in place of a page when the user's data could not be read: the error message, a sentence saying the user is still signed in, a Try again button that reruns the loads, the support block and logout.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `RegistrationCodeField`             | One labelled text input for a registration code, with the format of a code as its hint: the input library's `Input` of the `text` kind. It never rewrites what was typed or pasted and sets no limit on its length.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `RegistrationModeSelector`          | A choice among the ways to register: native radios in a fieldset, with the chosen mode’s panel, a snippet of the caller’s, under its radio. Only the chosen panel is in the document. With one mode the panel is rendered directly, and with none nothing is.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `TermsOfUse`, `TermsOfUseForm`      | The terms of use and the form for accepting them.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
